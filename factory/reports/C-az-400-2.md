## Points to review

- **git-fat**: not documented on Microsoft Learn; written from the project README (`.gitattributes` `filter=fat`, `git fat init`, `.gitfat` rsync remote, `git fat push/pull`).
- **Scalar**: the Learn training unit still calls it a ".NET Core application"; the chapter says Scalar ships with Git since 2.38 (from Git knowledge, not re-read on Learn). `scalar clone` creating a `src` folder is from knowledge.
- **GitHub repository roles**: GitHub docs now list a **Moderate** role between Triage and Write; included.
- **Rulesets**: org-level rulesets plan wording is inconsistent in GitHub docs (Team and Enterprise vs Enterprise); chapter says "also at organization level" without naming the plan. Evaluate mode attributed to GitHub Enterprise. "Restrict code coverage" ruleset rule stated as public preview.
- **Azure Load Testing**: Learn now files it under Azure App Testing. The config YAML page mixes a flat `failureCriteria` list and a `clientMetrics:` object, and `responseTimeMs` vs `response_time_ms`; the chapter uses `clientMetrics:` with `p90(response_time_ms)` from the metrics table.
- **PR diff coverage**: Learn says only the Visual Studio `.coverage` format is supported for the PR status; stated in the chapter, while the Code Coverage tab example uses Cobertura from coverlet.
- **From knowledge, not re-read**: `counter()` expression in `name:`; `fetchDepth` shallow default; npm `^`/`~` semantics; `RestorePackagesWithLockFile`, Central Package Management; `npmAuthenticate@0`, `PipAuthenticate@1`; `--api-key az` with NuGetAuthenticate; `git lfs migrate import`, `git lfs lock`; Git recovery commands; Microsoft L0–L3 test taxonomy; flaky test detection (stated only as "offered").
