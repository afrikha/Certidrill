## Facts verified on learn.microsoft.com (2026-11-17) worth a reviewer's eye

- RDP Shortpath: four options, host pool settings default Enabled, more restrictive setting wins, TURN range `51.5.0.0/16` UDP 3478, port-range policy (base 38300, pool 1000). RDP Multipath GA (public cloud and Azure Government), Windows App 2.0.559.0 / 2.0.1069.0, no setting of its own.
- QoS DSCP 46 and throttling only with Shortpath for managed networks (not reverse connect).
- Private Link: `connection` / `feed` / `global`, zones `privatelink.wvd.microsoft.com` and `privatelink-global.wvd.microsoft.com`, re-register provider, TCP 1–65535 to the connection endpoint, "Allow Direct UDP network path over Private Link".
- New VNets default to private subnets for API versions after 2026-03-31 (explicit outbound needed for activation/updates).
- Prerequisites page: ephemeral OS disks, Ultra OS disks, VM Scale Sets, Arm64 not supported for session hosts; Windows Server 2016–2025 supported.
- April 2026 Windows Server update changes default Kerberos encryption RC4 → AES-SHA1 (FSLogix shares must be upgraded).
- Microsoft Entra Kerberos for Azure Files now supports cloud-only/external identities with Entra-joined hosts (Azure public cloud only); `kdc_enable_cloud_group_sids` manifest tag.
- ANF: 3,000 concurrent active profiles per regular volume; one AD connection per NetApp account; Continuous Availability recommended.
- Session host configuration: pooled only, chosen at creation, can't be changed.
- Windows 10 ESU automatic for AVD session hosts (22H2); the page has an internal contradiction about policy enablement.
