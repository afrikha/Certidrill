- **RouteServerSubnet minimum size**: written as "/26 or larger", as the current Learn quickstarts (portal, CLI, PowerShell, dated 2025-09-17) state. Older material says /27; the Route Server FAQ gives no size.
- **Application Gateway v1** is left out (subnet table gives only the v2 figures: /24 recommended, 125 instances).
- **Default outbound access**: written from the article dated 2026-07-24 (private subnets by default for API versions released after March 31, 2026; portal already defaults to private).
