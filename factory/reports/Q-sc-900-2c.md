## Notes and doubts

- French terminology follows the course chapter 24 (« Gouvernance Microsoft Entra ID », « Protection Microsoft Entra ID »,
  « utilisateurs à risque », « connexions à risque », « détections de risque », « risque utilisateur »). The fr-fr Learn pages
  use slightly different forms for the reports (« Connexions risquées », « Détections des risques ») and a machine-translated
  product title (« Protection des ID Microsoft Entra »); I kept the course's forms for consistency.
- Joiner / mover / leaver: fr-fr Learn is machine-translated (« Nouveau », « Déplaceur », « Sortant »). The dropdown
  `sc900-2c-gov-joiner-mover-leaver` uses « une arrivée (joiner) », « un changement de poste (mover) », « un départ (leaver) ».
- The legacy risk policies inside ID Protection retired on October 1, 2026 (Learn): questions only mention risk-based
  Conditional Access policies. Learn now recommends the « Require risk remediation » grant for user risk; the questions keep
  « secure password change », which is still documented and is what the course teaches.
- `sc900-2c-rev-denied-guests` and `sc900-2c-gov-incompatible-access` (difficulty 3) are at the upper limit of SC-900 depth
  (a review setting, separation of duties checks); both are described in the Learn overview / SC-900 learning path, but a
  reviewer may prefer to lower their weight.
- « Microsoft Entra password protection » (distractor in `sc900-2c-idp-feature`) was not fetched in this task; its
  description relies on course chapter 22.
- Multi-stage access reviews (up to three stages) are in the course but one Learn page still flags a multi-stage action as
  preview, so no question depends on it.
