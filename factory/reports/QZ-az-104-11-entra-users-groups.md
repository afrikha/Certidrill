# QZ-az-104-11-entra-users-groups — doubts and notes

- **French "Assigned" membership type.** The glossary (`content/glossary.yaml`) says « Affecté » (not « Attribué »); the quiz uses « Affecté ». The FR chapter `11-entra-users-groups.fr.md` uses « Attribué (Assigned) » and « Attribué »: to harmonise (not changed, out of scope).
- **Licensing pages moved.** `entra/identity/users/licensing-group-advanced` and `licensing-groups-resolve-problems` now redirect to the Microsoft 365 admin page "Assign or unassign licenses to a group in the Microsoft 365 admin center" (`microsoft-365/admin/manage/manage-group-licenses`); Q8 and Q10 reference that URL. Bank questions that still cite the Entra licensing URLs may need checking.
- **Direct + inherited license.** The M365 page doesn't state that a direct license survives removal of the group license; Q10 relies on the AZ-104 training unit "Manage licenses" ("resulting user state is a combination…", "consumed only once"), which is cited.
- **Reprocess after fixing a conflict (Q8).** Learn says you "might need to reprocess"; the correct option says "remove the direct E1, and then reprocess", which is safe either way.
- **Group license assignment role.** "Least privileged roles by task" lists *User Administrator* (not License Administrator) as least privileged for "Groups > Assign license", while License Administrator is least privileged for assigning licenses to users. The chapter's table says "Assign licenses → License Administrator" without that nuance. Q3 is therefore limited to user accounts.
- **Q5 distractor path.** "Authentication methods > Password protection" (smart lockout) was not fetched; it is used only as a wrong option (smart lockout doesn't unlock AD DS accounts).
- **SSPR legacy methods.** Since 30 Sept 2025 methods are managed in the Authentication methods policy; the "Number of methods required to reset" setting is still on Password reset > Authentication methods (used as a distractor in Q5 only).
- Mock-exam overlap avoided: guest one-time passcode, License Administrator, dynamic-group manual add / Validate Rules, SSPR unlock without reset, guest account lifecycle, group configuration matching, conflicting service plans, SSPR scope with nested groups + reconfirmation 0 days, nested/direct/tenant-location licensing combination are not tested with the same decision in `questions/identities/`.
