## Decisions and doubts
- **Prompt flow variants not used**: Learn says Prompt flow (Foundry and Azure ML) retires on 20 April 2027 and is no longer recommended for new development. If the real exam still tests variant_0 / Batch run & Evaluate, the bank has no question on it.
- **Agent SDK**: the training unit 3 code uses the classic `AIProjectClient.from_connection_string` + `agents.create_agent`; the questions use the current `AIProjectClient(endpoint=...)` + `agents.create_version(agent_name, definition=PromptAgentDefinition(...))` from the Foundry Agent Service docs.
- **ai300-3c-pr-gate** relies on GitHub branch protection (required reviews and required status checks) and on a script exiting nonzero; these are GitHub facts, not stated on the Learn unit (which only posts a PR comment).
- **ai300-3c-inter-rater**: assumes "within one point" agreement includes exact agreement (consistent with the Learn example where 60 % + 33 % are both counted as acceptable).
- The prompt optimizer page (Foundry observability) could not be fetched (web-fetch budget), so no question covers it.
- Course chapter 33-prompt-management did not exist yet when the questions were written; alignment to check once it is.
