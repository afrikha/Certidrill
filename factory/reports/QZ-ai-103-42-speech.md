# QZ-ai-103-42-speech — notes

## Chapter vs current Learn (to fix in the chapter, not done here)

- **Voice Live, `input_audio_transcription.model`.** The chapter says `azure-speech` "works with non-multimodal models and agents". "How to use the Voice Live API" (fetched 2026-11-24) also lists `gpt-realtime`, `gpt-realtime-mini`, `azure-realtime`, `microsoft-realtime-flash-1` and `phi4-mm-realtime` as compatible. So `azure-speech`, with its phrase list and custom speech, also works with the realtime models. The page also lists models that the chapter doesn't name: `gpt-4o-transcribe-diarize` (gpt-realtime only), and `mai-transcribe` / `mai-transcribe-2` (preview, phrase list supported). q7 is built on the compatibility with `gpt-realtime`.
- **Voice Live agent mode appears to be preview.** The quickstart "Voice Agent with Foundry Agent Service (new)" uses `api_version="2026-01-01-preview"` and prerelease packages (`azure-ai-voicelive>=1.2.0b4`). The chapter doesn't flag this, and the mock question `ai103-4b-agent-mode-facts` tests agent mode as its answer. The quiz doesn't test agent mode. The required role is now called **Foundry User** (renamed from Azure AI User). The GA Voice Live API version on the how-to page is `2026-04-10`.
- **Live Interpreter.** "How to translate speech" covers real-time speech-to-speech translation with Live Interpreter, including an LLM-based option. The chapter (4.2.4) doesn't mention it, yet the mock question `ai103-cs3b-desk-interpreter` has it as the correct answer. Add a line to the speech-translation section, or check the case-study question.
- **Structured outputs and audio models.** The structured outputs page lists `gpt-audio` and `gpt-audio-mini` as not supported. Section 4.2.3 doesn't say this, and it's a real trap: an audio model plus a guaranteed schema needs a second step. q8 tests it.
- **Batch transcription limits that the chapter doesn't give.** These come from "Create a batch transcription": diarization works only on mono audio; channels 0 and 1 are transcribed by default (`channels` property); language identification works only with base models, and adding a custom model makes it fall back to base models ("if you need both, use real-time speech to text"); a custom model is referenced through its `self` URI and needs no endpoint. q3 and q10 use these facts.
- **Text to speech.** The batch synthesis API is GA. The Long Audio API **retires on April 1, 2027**. The chapter only says that long-form text goes to batch synthesis, which is correct.
- **Keyless authentication.** "How to configure Microsoft Entra authentication" (Speech SDK) requires a **custom domain** for the Speech resource, which can't be undone, plus the **Cognitive Services Speech User** or **Cognitive Services Speech Contributor** role, and `SpeechConfig(token_credential=..., endpoint=...)`. The chapter's exam trap says that the quickstarts use keys "for learning only" and that Microsoft recommends a managed identity. I didn't find that wording on the pages I fetched, though the recommendation stays sound. q4 relies only on the facts of the Entra authentication page.

## Facts not verified, so left out or worded carefully

- Whether batch transcription results tag each phrase with its channel. The page says that `channels` lists the channels to process (0 and 1 by default) and that diarization isn't available for stereo. q3 says "use the channel of each phrase". I believe the results include the channel, but I didn't read it on the page.
- The `openai` value of `voice.type` in Voice Live. The how-to page mentions it only as unsupported for `microsoft-realtime-flash-1`. q7 uses it as a wrong option.
- `SpeechConfig.output_format` (simple or detailed results) is used as a distractor in q2. It isn't on the pages I fetched, although it's a real SDK property.
- `endpoint_id` on `SpeechTranslationConfig`. The translation how-to doesn't show it. The custom speech overview says that custom models work with speech translation. q5 and q9 say "configure the speech translation configuration with the custom endpoint" without naming the property.
- Whether Content Understanding `prebuilt-callCenter` judges tone from the audio or from the transcript: unverified, so the quiz doesn't use it.
- French: « reconnaissance ponctuelle » for single-shot recognition (q3 d) and « informations d'identification de jeton » for token credential (q4) weren't checked on fr-fr Learn. Check them against the glossary.
