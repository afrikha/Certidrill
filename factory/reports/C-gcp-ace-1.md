## Doubts and deviations
- **Possible error in an existing question, `questions/setup/gcpace-1c-lock-billing-link.yaml`** (not my file, not edited): its explanation says unlocking a locked billing link needs Billing Account Administrator, which the project owners lack. The "Secure the link" page lists, for unlocking, project-side roles (Project Billing Manager with Project Browser, **or Project Owner**) **OR** Billing Account Administrator. The stem's users are project owners, so they could unlock: the correct answer no longer meets "prevent these users". Since changing a link always needs project-side roles, anyone able to change it from the project side can also unlock it: a lock protects against accidental changes, not against those users. Suggest rewording the requirement to "prevent accidental changes of the billing link"; for a fix agent to check.
- **Gemini Cloud Assist is Preview** (overview and setup pages, Pre-GA terms) although the guide names it in 1.1.11. Chapter 12 teaches what it does, the setup APIs/roles, the data residency/CMEK caution, and says it is Preview; Cloud Asset Inventory stays the answer for auditable inventory.
- **Standalone organizations**: the overview page gives no launch stage and no gcloud creation command (creation is automatic for new Free Trial sign-ups). Delete/restore procedures are on a separate page that I didn't fetch; the chapter doesn't cover them.
- **Workforce Identity Federation OIDC provider command**: I used the implicit-flow variant (`--web-sso-response-type=id-token`, `--web-sso-assertion-claims-behavior=only-id-token-claims`, no client secret) as described on the Entra ID page; the attribute mapping `assertion.groups` is illustrative.
- **Quota error code**: "HTTP 429 `RESOURCE_EXHAUSTED`" for rate quotas is from general knowledge; the quotas overview only says "a quota error". The quota ID in the `preferences create` example is a placeholder (`QUOTA_ID`, from `gcloud quotas info list`) because I couldn't confirm the exact Compute Engine regional CPU quota ID.
- **Implied firewall rules priority 65535** and **auto mode subnet size** aren't stated on the fetched pages; the chapter says "lowest priority" (no number) and doesn't give the /20 size.
- **`_Required` 400-day retention**: the buckets page only says the retention can't be changed; 400 days is from the PCA course and audit log docs (not re-fetched).
- **Billing account types**: self-serve payment cadence ("billing threshold or monthly") and invoiced payment means (bank transfer or check) are from general knowledge; subaccounts are only mentioned for resellers.
- **Project-level budgets**: the budgets page names the permission (`billing.resourcebudgets.write`) but no predefined project role; the chapter only documents billing-account budgets' roles.
- `gcloud projects move` exists only as `gcloud beta projects move` (reference and "Move a project" page); the chapter says so.
- No partial credit is published for multiple select; the chapter says Certidrill scores all or nothing (blueprint.yaml).
