## Deviations and decisions

- **Code blocks use the `text` language**: the validator allows only bash, powershell, json, bicep, kusto, yaml, text, so Python snippets are fenced as `text`.
- **Length**: prose is 830–1,150 English words per chapter; `wc -w` on the whole file (tables, markers and code included) gives 1,000–1,301, comparable to the AZ-900 model 23-storage (1,293). Chapters 11, 12, 13, 21 were trimmed once to get there.
- **Chapter 00** follows the AZ-900 model (four sections, no key-points section).
- **Portal labels are kept in English in French** (Discover, Models, Deploy, Instructions, Tools, Web search, Save as agent, New chat, Home, Text to image): the fr-fr portal labels could not be verified.
- **French terms**: study-guide wording for the principles (impartialité, inclusion, responsabilité), with a note that Learn also writes « équité » and « inclusivité »; « invite système / invite utilisateur », « terrain de jeu », « jeton », « analyseur », « schéma », « score de confiance », « extraction d'expressions clés », « résumé » (the study guide says « synthèse »), « embeddings » left in English as on the fetched fr-fr unit. « API Responses » and « API Chat Completions » keep the English API name (the fr-fr unit writes « API Réponses »). "Redact" is rendered « masquer » (the fr-fr unit has a typo there).

## Doubts to review

- **2.2.2 (spoken prompts with a multimodal model)** is not covered by a unit of the learning path. The section is written from the Foundry quickstart "Get started with Azure OpenAI audio generation" (models `gpt-audio`, `gpt-audio-mini`, Chat Completions API, `input_audio`, `modalities`, `audio`). The real exam may show a different API surface.
- **Two client styles exist on Learn** for the chat client: `OpenAI(base_url=..., api_key=...)` (training unit) and `AIProjectClient(...).get_openai_client()` (Foundry SDK quickstart). Chapter 21 shows the second as the main sample and describes the first. The snippet combines the quickstart client with the unit's `input` messages, `temperature` and `max_output_tokens`.
- **Agent client**: the training unit references the agent with `extra_body={"agent": {"name": ..., "type": "agent_reference"}}`; the quickstart uses `get_openai_client(agent_name=...)` with `conversations.create()`; the lab says the portal sample also passes the agent version. Only the first form is in the chapter.
- **Portal navigation differs between Learn and the labs** (speech and language playgrounds: "Build > Models > AI services" in the units, "Build > Services" in the labs). The chapters name the playgrounds without a click path for those.
- **Model names** (GPT-4.1, GPT-5 family, GPT-Image-1.5, FLUX, Sora, Phi-4, text-embedding-3-small, `gpt-audio-mini`) are those Learn names today; they will age.
- Speech snippet: the meaning of the `recognized` event ("final text of each phrase") is from the training sample's handler names, not from an explicit sentence.
- Image schema examples in chapter 24 (chart, defect, shelf fields) are illustrative fields built on the scenarios Learn lists; only the meeting-room example is Learn's.
- Not verified, left out: whether the certification expires, number of questions (the "35 to 45 in practice" comes from the exam profile), AI-900 retirement date.
- Voice Live, Foundry IQ, multi-agent systems and fine-tuning are out of scope per the profile and are not taught.
