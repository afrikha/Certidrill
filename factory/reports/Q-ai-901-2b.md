## Doubts to review

- **Learn is not consistent on the agent reference key.** The training unit writes `extra_body={"agent": {...}}`; the file search tool page writes `extra_body={"agent_reference": {...}}`. No question asks for the key: they test the `agent_reference` type and the agent name only. Chapter 21 shows the first form.
- **Agent version.** The lab says the portal's sample code also passes the agent version. No question depends on which version a name-only reference resolves to; I could not verify it.
- `ai901-2b-agent-compare-tools` (hard) rests on one troubleshooting row of the Playgrounds page: tools are hidden in compare mode.
- `ai901-2b-agent-yn-web-search`, statement 3: "general web search needs no separate Bing resource or project connection" is from the web search tool page of Foundry Agent Service.
- `ai901-2b-client-az-login` and `ai901-2b-client-dd-connect` state that Microsoft Entra ID is the only authentication the project client supports (Azure AI Projects client library page).
- `ai901-2b-text-dnd-methods` and `ai901-2b-text-dd-pii-output` use `analyze_sentiment`, `extract_key_phrases`, `recognize_entities`, `key_phrases`, `sentiment`, `confidence_scores`: they are on the Text Analytics client library page, not in the training unit, which only shows `detect_language` and `recognize_pii_entities`. The same Learn overview now labels sentiment analysis, key phrase extraction and summarization in Azure Language as legacy capabilities.
- `ai901-2b-audio-dnd-models` names `gpt-4o-mini-transcribe` (listed as preview) and `gpt-4o-mini-tts` from "Foundry Models sold by Azure", and `gpt-image-1` as the unused item. Model names will age.
- `ai901-2b-audio-text-only-output`: the quickstart's modality table lists "audio in, text out" as supported; the page does not show a sample with `modalities=["text"]`, so the options describe the request instead of quoting a value.
- `ai901-2b-audio-speech-vs-model`: batch transcription and custom voice come from the Azure Speech overview; the "use Azure Speech rather than the model" framing follows the decision table of chapter 22, not a Learn sentence.
- Reference titles are the page titles reported by the fetch tool; a few differ from the H1 (for example "What is Microsoft Foundry Agent Service?" has the H1 "Agents in Microsoft Foundry"). Worth a pass by the reference checker.
