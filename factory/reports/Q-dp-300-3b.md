## Facts taken from the course chapter or from knowledge, not checked on a fetched page

- `sys.server_resource_stats` is a managed instance view and `sys.dm_db_wait_stats` gives the waits of an Azure SQL database. Both appear only in distractors or explanations.
- `SOS_SCHEDULER_YIELD` as the CPU-pressure wait type: a distractor in `dp300-3b-dmv-wait-types`.
- `SET XACT_ABORT ON` rolling back a transaction after a client timeout or attention (`dp300-3b-blocking-timeout`). The blocking page lists it as a fix for that scenario but doesn't describe the attention behavior itself.
- Implicit conversion: `nvarchar` has higher precedence than `varchar`, so the column gets converted and can't be sought (`dp300-3b-construct-implicit`). The wording avoids saying a seek is always impossible.
- `SET SHOWPLAN_XML ON` doesn't run the query. `sys.dm_exec_query_plan` returns the compiled (estimated) plan. Both are distractors.
- `LAST_QUERY_PLAN_STATS` is off by default. The `CLEAR PROCEDURE_CACHE` database scoped configuration is a distractor.
- `RESAMPLE ON PARTITIONS` merging partition statistics into the table-level statistics (explanation only).
- `sys.index_resumable_operations` showing progress: the ALTER INDEX page says it gives the status. The question asks only that you query the view, not for a column name.
- Index maintenance log volume raising replica latency: Learn states the latency effect but not that it comes from the log.
