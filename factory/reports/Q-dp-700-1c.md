## Course discrepancy (for the course owner)
- Chapter 13 (`onelake-security` section) gives the SQL endpoint switch path as "Security > Data access mode settings > Use OneLake security for tables". The current Learn page (updated 2026-08-31) says: Security tab > View data access mode > Data access mode settings > **User's identity access mode** / **Delegated identity access mode**. The questions use Learn's wording.
- Learn: switching modes cancels the queries on every SQL analytics endpoint in the workspace and deletes the existing SQL roles. The course doesn't mention this, and `dp700-1c-ols-switch-mode` tests it.
- Learn: when you enable SQL audit logs, all actions are selected and kept for nine years by default. The course doesn't mention this.
