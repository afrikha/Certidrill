- Global Azure DevOps PATs are being retired, but Learn gives two dates: the PAT page says global PATs stop working on 2027-01-27 in one place and 2026-12-01 in another; the Sprint 270 notes say 2026-12-01 (the 2026-03-15 creation block is struck through). The chapter gives no date.
- Azure DevOps public projects are retired; existing ones convert to private in 2027.
- ARM service connections: WIF is the default; conversion only for automatic, single-project connections, revert within 7 days; unused connections may be disabled after 100 days (not written in the chapter); Azure DevOps issuer retires 2027-07-01 (not written).
- GitHub repository roles now include **Moderate** (between Triage and Write) — included.
- `actions/create-github-app-token@v3` uses `client-id` (not app-id); installation tokens expire after 1 hour.
- Key Vault: Azure RBAC default from API 2026-02-01.
- GHAS for GitHub = GitHub Secret Protection + GitHub Code Security (Team / Enterprise Cloud); GHAS for Azure DevOps = Secret Protection for Azure DevOps + Code Security for Azure DevOps.
- GHAS ↔ Defender for Cloud integration: prerequisites (GHAS license, Defender CSPM, GitHub connector, agentless code scanning, org owner, commercial clouds), Runtime Risks campaign filter, "Generate GitHub issue". A GitHub changelog title (search result only) says code-to-cloud visibility became GA on 2026-05-05; not written in the chapter.
- Defender for Cloud CLI (`defender scan image`, task `MicrosoftDefenderCLI@2`) needs Defender CSPM; GA/preview status not stated on Learn.
- Defender for Containers registry rescan window is 30 days (pushed or pulled), not 90.
- VM insights now offers OpenTelemetry metrics to an Azure Monitor workspace (recommended for new deployments) or logs-based metrics (classic). Learn pages disagree on scale set support for the new metrics experience; the chapter doesn't claim it.
- Application Insights recommends the "Microsoft OpenTelemetry Distro" (.NET, Node.js, Python) and "Azure Monitor OpenTelemetry Distro" (Java).
- `actions/checkout@v6`, `github/codeql-action/*@v4`, `actions/dependency-review-action@v4`, `azure/login@v2` (versions seen on fetched pages).
