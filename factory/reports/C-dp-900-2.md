## Scope decisions

- Azure Synapse Analytics and Azure HDInsight are no longer taught by the current large-scale analytics module (only Microsoft Fabric and Azure Databricks, plus Azure Data Factory as a standalone service): left out of chapter 41.
- Azure Stream Analytics, Azure Event Hubs, Azure IoT Hub, Apache Kafka and ADLS Gen2 are still named in the current real-time module: kept in chapter 42.
- Cosmos DB: the Learn unit now says Azure Cosmos DB for PostgreSQL is "on a retirement path" and recommends Azure DocumentDB for full MongoDB compatibility. Chapter 32 mentions the PostgreSQL status in one sentence (no date) and does not mention Azure DocumentDB.
- Power BI storage modes (Import, DirectQuery, Direct Lake) are included in 4.3.2; DirectQuery comes from the Power BI docs, not from the training module.

## Left out because unverified or inconsistent

- Retirement date of the Power BI Q&A visual: two Learn pages give different dates (December 2026 / February 2027). Not mentioned.
- "The API of an Azure Cosmos DB account cannot be changed after creation": not stated on the fetched pages; the chapter only says the API is chosen at account creation.
- Capacity/licence requirements for Copilot in Power BI: not included (out of fundamentals scope).

## French terminology choices

- Azure Cosmos DB API names kept in English (`Azure Cosmos DB for NoSQL`, ...) per the brief (product names stay in English); the fr-fr Learn unit writes « Azure Cosmos DB pour NoSQL ».
- Consistency levels: French name + English in parentheses, e.g. « Obsolescence limitée (Bounded staleness) ».
- « lakehouse » / « data lakehouse » kept in English as on fr-fr Learn; « schéma sur lecture (schema-on-read) », « schéma en flocon de neige », « récepteur (sink) », « requête perpétuelle ».
- Fabric item names in English (Real-Time hub, Eventstream, Eventhouse, KQL queryset, Real-Time Dashboard, Activator, Lakehouse, Warehouse), with a French gloss where Learn has one.
- Power BI visuals: « histogramme » = column chart, « carte (card) » vs « carte géographique (map) », « segment (slicer) », « treemap (graphique de compartimentage) », « vignette » = tile.
