- Foundry IQ knowledge base connection is **preview** (`2026-08-01-preview`); `ai103-5b-kb-mcp-tool` uses that version. The .NET sample on the same page uses `2026-05-01-preview`.
- `"CognitiveSearch"` and `"AzureOpenAI"` (connection categories, distractors in `ai103-5b-kb-mcp-tool`) come from general knowledge, not from a page fetched in this task.
- `ai103-5b-read-faxed-notes` assumes PNG input is supported by prebuilt-read (image formats are supported; the format list itself was not fetched).
- The Python readme says model_deployments maps model names to deployments, while the REST page maps aliases; questions avoid relying on the exact key format.
- The web-fetch budget ran out once mid-task; all facts used were verified before or after.
