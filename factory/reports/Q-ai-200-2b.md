## Stated from general PostgreSQL / psycopg knowledge (not on a fetched Learn page)

- psycopg 3: no autocommit by default, `close()` outside `with` discards the open transaction; `?` placeholders unsupported; `executemany`, `fetchone`, `cursor.copy()` for `COPY ... FROM STDIN` (ai200-2b-missing-commit, -param-query, -cursor-methods, -bulk-load).
- libpq sslmode semantics of `allow` / `prefer` (ai200-2b-entra-uri).
- System-assigned managed identity role name = app name (display name of its service principal) (ai200-2b-identity-role).
- `json` has no default GIN operator class; hash index equality only; B-tree on whole jsonb (ai200-2b-chunks-table, -gin-containment, -json-range).
- `vector` extension needs no restart / no preload (ai200-2b-enable-vector-order).
- `maintenance_work_mem` for HNSW builds (Learn states it for DiskANN only) (ai200-2b-concurrent-build).
- `shared_buffers` cannot be SET per session; `SET SESSION` persists after COMMIT; HA standby not readable (ai200-2b-build-memory, -ef-search-local, -read-replica).
- E8ds_v5 = 64 GiB, D8ds_v5 = 32 GiB, D16ds_v5 = 64 GiB derived from the 4 GiB/vCore (D) and E4ds_v5 = 32 GiB figures (ai200-2b-sku-memory).
- Standard SSD is not offered (the storage page lists only Premium SSD and Premium SSD v2) (ai200-2b-storage-type).
