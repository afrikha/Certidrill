## Points to review

- **Copilot Studio menu names.** The Learn module says Power Platform admin center **Security > Threat Protection >
  Microsoft Defender - Copilot Studio AI Agents** for the Defender path; the Copilot Studio doc for a custom provider says
  **Security > Threat detection > Additional threat detection** (per environment). Both are taught as separate paths.
  Whether the Defender path is per environment isn't stated: not claimed.
- **Defender for Storage**: malware scanning default cap is now **10,000 GB** per account per month (older material says
  5,000). Activity monitoring alert examples are paraphrased generically. No CLI shown (pricing extension syntax not verified).
- **Defender for Databases**: "Select types" link and resource-level enablement of Defender for Azure SQL are from
  general knowledge of the portal (the fetched quickstart only describes Databases = On). `az security pricing create`
  names `SqlServers` and `OpenSourceRelationalDatabases` not re-fetched.
- **SQL**: Managed Instance public endpoint port 3342 (disabled by default), connection policy value `Default`, and the
  table contrasting TDE / Always Encrypted / dynamic data masking / row-level security are from general knowledge (stable facts).
  `az sql server audit-policy update` parameters and `az sql server update --enable-public-network` not re-fetched.
  T-SQL is in `text` blocks (no SQL language allowed).
- **Network**: `New-AzIpsecPolicy` parameters not on the fetched page (well-known cmdlet). Private endpoint network
  policies ("NSG/UDR apply only when network policies are enabled on the subnet") not re-fetched. Secured hub requires
  Standard Virtual WAN taken from the AZ-700 chapter. Entra Private Access licensing not taught (page says only "requires licensing").
- **Storage**: `az storage container policy create` / `generate-sas --policy-name` / `--as-user` syntax from general knowledge.
  SAS expiration policy action (log vs block) left out (not verified).
- **DSPM**: the training covers **DSPM for AI (classic)**; the newer unified DSPM experience is only mentioned. The role
  is given as "Compliance Administrator or equivalent" as on the page.
- **French terminology**: Agent ID terms (« identité d'agent », « blueprint d'identité d'agent », « compte d'utilisateur
  d'agent ») follow the K-sc-500-cs4 report (fr-fr CA for agents page). « sponsor », « propriétaire (owner) »,
  « responsable (manager) », « rayon d'impact (blast radius) », « découverte de contenu restreinte », « contrôle d'accès
  restreint » were not checked on fr-fr pages. Many Defender, Purview and Microsoft 365 admin center UI labels are kept in
  English (no verified French portal labels).
