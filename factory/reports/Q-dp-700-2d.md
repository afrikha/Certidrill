## Written from general knowledge (please review)

- Event Hubs connector: the event body is binary (the Learn sample casts it to a string). Without a checkpoint, the query starts again from the starting position set in `ehConf`. The stem of `ss-checkpoint-reset` now states this starting position.
- `ss-job-retry` option d and `ss-hourly-available-now`: I took the `availableNow` behaviour (process what is available, then stop) from the Databricks triggers page. The batch question uses a Delta source, not Event Hubs, because I'm not sure the Event Hubs connector supports `availableNow`.
- `ss-join-watermarks`: an inner stream-stream join needs watermarks on both sides plus an event-time range condition before its state is cleaned up. That comes from Apache Spark docs I didn't fetch. The stem gives the range condition, so the answer only adds the watermarks.
- `ss-write-statements` s3: when a micro-batch takes longer than the processingTime interval, the next one starts as soon as it finishes, and micro-batches never overlap. This is Spark behaviour I didn't fetch.
- `ss-optimize-write`: I assume optimized write is off. Its default in Fabric depends on the runtime and resource profile, so I didn't verify it.
- `ss-foreachbatch-merge`: the method names (`merge`, `whenNotMatchedInsertAll`, `whenNotMatchedBySourceDelete`, `DeltaTable.update`) come from the Delta Lake Python API, not from a fetched page.
- `win-session-visits`: `OVER (PARTITION BY userId)` gives each user independent sessions. The max-duration check can make a session last up to twice maxDuration, so I worded the stem as "the window must use a maximum duration of 120 minutes". That wording may hint at the session window.
- `win-kql-functions`: `prev()` and `row_cumsum()` (with its restart argument) were not fetched.
- `kql-expand-policy`: the `mv-expand r = Payload.readings` syntax was not fetched.
- `es-edit-publish`: the explanation says that a running eventstream keeps its current logic until you publish. That is inferred, not stated on Learn.
- French UI labels I couldn't check against the fr-fr pages: Modifier, Actualiser, Publier, Résultat du test, onglet Optimisation, « Traitement des événements avant l'ingestion », « étiquettes d'étendue (extent tags) ».
