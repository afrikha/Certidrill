## Course disagreements with Learn (chapter 42, for the course owner)

- `42-service-endpoints` says a storage account accepts 200 virtual network rules. Learn ("Firewall rules and network access for Azure Blob, Data Lake, Queue, and Table Storage", fetched 2026-11-17) says **400** virtual network rules and 400 IP rules per account.
- `42-service-endpoints` says in its comparison table that a service endpoint works in "Any region (Azure SQL: same region only)". The same Learn storage page says `Microsoft.Storage` covers accounts **in the same region** as the virtual network, `Microsoft.Storage.Global` covers any region, and a subnet can have only one of the two. Questions `az700-4b-sec-storage-global` and `az700-4b-sec-effective-routes` follow Learn. They use France Central / West Europe and West Europe / East US, which are not paired regions.
- `42-service-endpoints.fr.md` uses « réseau virtuel appairé ». The glossary asks for « peering ». The questions use « relié par peering ».
