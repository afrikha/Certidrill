## Corrections made after verification (differences with what one might remember)

- Serverless: General Purpose and Hyperscale only; auto-pause in Hyperscale is still labelled preview. The "dev database" drop-down therefore offers General Purpose / Business Critical / Premium and not Hyperscale.
- Azure Hybrid Benefit applies only to provisioned compute of the vCore model (not DTU, not serverless) and is not offered for new Hyperscale databases.
- Hyperscale: durable and non-durable memory-optimized tables are not supported (only table types, table variables, natively compiled modules), so the In-Memory OLTP multi-select keeps Hyperscale as a wrong option.
- Backup storage redundancy now has four options (LRS, ZRS, GRS, GZRS); GZRS is used as a distractor of the residency question.
- PostgreSQL flexible server: Learn says the standby "comes online immediately" after a failover is triggered but does not use the word "automatic"; the question avoids it.
- SQL Managed Instance stop/start: General Purpose only; compute and licensing are not billed, data and backup storage are.
