## Points to review

- **Learn changed its guidance**: the BGP FAQ now says not to add the /32 of the on-premises BGP peer to the local network gateway's Address space. The new rule is tested in `az700-2a-lng-bgp-settings` (s1 = No). Older material and some practice sources say the opposite.
- **SSTP**: Learn says enabling SSTP is no longer supported since August 31, 2026, and SSTP connections end March 31, 2027. Two questions depend on this (`p2s-tunnel-facts` s3 and the `ikesstp` option of `p2s-tunnel-ps-config`). No question recommends SSTP.
- **Non-AZ SKUs**: new VpnGw1–5 gateways have been blocked since November 1, 2025 (`sku-az-generation` s1 = No). VpnGw1AZ appears only under Generation1 in the SKU table.
- **Extended network for Azure**: Learn contradicts itself. The intro says two Windows Server 2019 VMs. The planning and troubleshooting sections require Windows Server 2022 Azure Edition in Azure and allow 2019 or 2022 on-premises. The questions follow the detailed sections. The same page also says the WAC extension isn't on the feed of WAC version 2410. Questions don't mention this.
- **Symmetric routing** (`s2s-ha-symmetric`): the FAQ says to adjust routing (BGP attributes or traffic selectors) *or* use active-standby. Only the active-standby option is offered, so the answer stays unique.
- **Active-standby failover time**: written as "about 1 to 3 minutes" for unplanned events, from the highly-available article. The active-active article no longer gives numbers.
- **The FAQ's IANA reserved ASN "429496729"** looks truncated (4294967295). No question uses it.
- **Left out because not verified**: the Basic SKU IKEv2 point-to-site connection limit (the table gives none), Virtual WAN per-hub S2S connection limits, and the French portal labels of the connection settings (kept in English, e.g. "Use policy based traffic selector", "Connection Mode").
