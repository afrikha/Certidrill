## Corrections made after the fetches (course chapters may need the same)

- Azure Storage Mover: the supported-pairs table lists NFS sources only towards Azure file shares (NFS 4.1), not towards blob containers; SMB sources go to blob containers or SMB Azure file shares. `az305-4c-data-storagemover` therefore uses SMB shares to blob containers. Chapter 43 does not state a pair, so it is not wrong, but an NFS-to-blob question should not be written without rechecking.
- Azure Bastion: the SKU table is on `bastion-sku-comparison` ("Choose the right Azure Bastion SKU to meet your needs"), not on the configuration settings page.
- Azure Database Migration Service: the supported-scenarios page also lists online migration of PostgreSQL to Azure Database for PostgreSQL flexible server, and MySQL online and offline. Chapter 43 only names the PostgreSQL migration service; `az305-4c-db-opensource-tools` does not offer DMS in the PostgreSQL slot, so its answer stays unique.
- Business case page H1 is "Business case (preview) overview".
- VMware HCX is an optional add-on of Azure VMware Solution (wording adjusted in `az305-4c-mig-tools-match`).

## Stated from general knowledge, not found on a fetched page

- Azure SQL Database cannot restore a native SQL Server backup file (`az305-4c-db-offline-methods`); the fetched overview only documents BACPAC for SQL Database.
- Transactional replication needs a primary key on published tables (given as a stem fact in `az305-4c-db-sqldb-min-downtime`, not as the deciding fact).
- Assessment setting labels "As on-premises" and the performance history values 1 day / 1 week / 1 month (`az305-4c-assess-sizing`): the fetched page words the criterion "as-is on-premises" and only gives one-day and one-week examples plus one month of stored data.
- The Map feature of VM insights requires agents on the monitored machines (distractor in `az305-4c-assess-dependencies`).
- SSMA for Oracle produces an assessment report and converts PL/SQL to Transact-SQL: the fetched page only says "detailed code assessment and conversion" and lists the targets.
- Azure Data Factory reads Amazon S3 and SFTP sources; AzCopy is the scripted command-line tool (`az305-4c-data-online-tools`); the data transfer page names the tools without those details.
- Azure Data Box can load Azure file shares (`az305-4c-data-hybrid-transfer`): the overview page confirms SMB copy, import and export, the 120 TB and 525 TB models and the Storage Mover catch-up, but the summary did not show Azure Files as a target.
- ExpressRoute Local is the cheapest SKU for large egress (`az305-4c-hyb-er-local`): the FAQ says egress is included in the Local price and paid on Standard and Premium; prices themselves are on the pricing page, which is not Learn. The options are the three SKUs only (no data plan names, which the FAQ does not define).

## Deviations and doubts

- `az305-4c-mig-vmware-sequence` is an `ordering` question because the task's type mix asks for one, although the exam profile says step ordering is not an AZ-305 format. It orders the phases of an Azure Migrate migration (discover, replicate, test, migrate), not portal steps.
- `az305-4c-assess-appliance-count` tests the appliance discovery limits (5,000 Hyper-V servers, 1,000 physical servers), which is closer to recall than to design.
- `az305-4c-hyb-er-resiliency` accepts a site-to-site VPN backup as a complete answer to "stay connected if the peering location fails". The fetched pages confirm it works as a passive backup and add that Microsoft does not recommend it for latency-sensitive, mission-critical or bandwidth-intensive workloads; the explanation says so.
