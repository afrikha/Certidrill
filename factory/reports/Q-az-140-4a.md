## For the course owner (chapter 41)

- The built-in role is named **Workbook Contributor** (singular) on the built-in-roles/monitor page. Chapter 41 says "Workbooks Contributor" in EN and FR. The questions use the exact name.
- According to manage-app-groups, when a user has access to both a desktop and a RemoteApp application group on the same host pool, the host pool's preferred application group type decides which one they get. Chapter 41 doesn't say this. Question `app-not-visible` therefore puts the RemoteApp group on a second host pool so the scenario has only one correct answer.
- The FR text uses « workbook », the same word as the course and the FR objective titles. The AZ-104 glossary says « classeur ». The two should be made consistent.
