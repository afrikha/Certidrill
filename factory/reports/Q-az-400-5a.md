## Deviations

- GitHub-only features (Projects charts, organization Actions metrics, repository traffic, workflow run notifications, `failure()` expression) are referenced on docs.github.com, since no Learn page covers them. Where it applies, the Learn training unit "Insight and automation with projects" is added too.
- Release annotations and end-to-end transaction details: the old URLs (`app/annotations`, `app/transaction-search-and-diagnostics`) now serve the page with canonical URL `app/failures-performance-transactions` ("Investigate failures, performance, and transactions with Application Insights"). The references use the canonical URL.
- The VM insights Performance page (`vm/vminsights-performance`) is now titled "Analyze the health and status of your virtual machine with Azure Monitor".

## Facts left out (not verified)

- W3C `traceparent`/`tracestate` header mapping: the correlation page now redirects to Application map, and the classic SDK page didn't show it. No question tests the header names.
- `sum(itemCount)`: the OpenTelemetry sampling page only uses `avg(itemCount)`. The sampling question is based on standard metrics not being sampled.
- Azure Pipelines app for Teams or Slack, and the Teams service hook (Office 365 connector retirement status unclear). The chat question uses the Slack service hook, which the service hooks page lists.
- The filter fields of the Build completes notification template. The question only uses "a filter on the status", and the stem makes billing-ci the only pipeline.

## Facts worth a reviewer's eye

- Audit streaming to Azure Monitor Logs now asks for the workspace **resource ID + tenant ID** and a sign-in to Azure, not a workspace ID and key.
- The VM insights Azure Policy initiatives support only the logs-based experience. The Dependency agent and Map retire on 30 June 2028.
- Historical charts in GitHub Projects need GitHub Team or Enterprise Cloud for organizations (Learn). The stem of the yes/no question uses Enterprise Cloud.
- Live metrics API keys were retired on 30 September 2025 (Entra authentication instead). Not tested.
