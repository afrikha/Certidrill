## Course inconsistencies found (chapter 71, for the course owner)

- "To create and run data collector sets, Performance Log Users": the Security Groups page says that since Windows Server 2016 members of Performance Log Users **can't create** data collector sets (access denied) and need the *Log on as a batch job* right to start logging or modify sets. Question `az802-7a-dcs-statements` follows the Learn page.
- VM insights Map / Dependency agent: deprecated, no new portal onboarding since 2025-09-30, retirement 2028-06-30 (`vminsights-maps-retirement`, 2026-08-24). The chapter presents the Map view without this note. Questions only use the Dependency agent as a distractor.
- Course thresholds (Processor Queue Length, Pages/sec) are not on Learn; questions use the thresholds of "Troubleshoot performance problems in Windows" (Available MBytes, % Committed Bytes In Use, disk latency, % Idle/% Privileged Time).
- Performance counters to "Azure Monitor Metrics" is marked **preview** in `vm/data-collection` (not used in questions).

## Not verified on a Learn page (kept as stable knowledge)

- Default gateway outside the subnet breaks routing to other subnets (hotarea SRV13); `Test-NetConnection -TraceRoute` relies on ICMP; WinRM disabled by a GPO stops collector-initiated subscriptions (stated in the stem).
- GPO setting name "Configure target Subscription Manager" not confirmed (the WEF page doesn't name it): options say "target subscription manager" generically.
- The WAC Azure Monitor page still describes the MMA; questions don't name the agent WAC installs.
- System Insights event channel name (Microsoft-Windows-System-Insights/Admin) and the 3:00 AM default schedule were not used (not on fetched pages).
