## Doubts and deliberate choices
- Premium SSD v2 and availability sets: the SAP storage planning guide (updated 2026-07) says it isn't supported, but the managed disk types page only says that in most zonal regions it attaches to zonal VMs. No question tests Premium SSD v2 with availability sets; the availability-set statement uses Ultra Disk, which the disk types page clearly excludes.
- Premium SSD v2 maximum throughput per disk differs between pages (1,200 MB/s on the HANA Premium SSD v2 page, 2,000 MB/s on the disk types page). Not used.
- `az120-2c-smb-share-roles`: the role Storage File Data SMB Share Reader isn't named on the SAP SMB page; I relied on the built-in role and didn't fetch the built-in roles page.
- `az120-2c-lvm-stripe-order` uses XFS (`mkfs.xfs`) as in the Learn examples; Learn says only that the file system must be SAP-supported (SAP Note 2972496).
- `az120-2c-afs-account-count` relies on Microsoft's "in general" guidance (at most five SAP systems per account, no prod/non-prod mixing); the stem says so explicitly.
- `az120-2c-wa-cli`: `--accelerated-networking` was replaced with `--disk-caching` after checking that `az vm update` doesn't have the former.
- `az120-2c-cache-hotarea` uses a P70 (16 TiB) disk instead of P50 for the "caching not supported for disks of 4 TiB and larger" prompt, to avoid the 4 TiB boundary.
- Instance snapshot backup (Azure Backup) is GA with the standard policy; HSR snapshot support and vaulted snapshots are preview (Enhanced policy) and weren't tested.
