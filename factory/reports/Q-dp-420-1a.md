## Doubts / deviations
- The CLI reference still says the `--max-throughput` minimum is 4000. The autoscale page says 1,000 (entry point 100–1,000 RU/s). The questions follow the autoscale page and never state the CLI figure.
- `dp420-1a-ru-operation-costs-hot` relies on the documented ratios (point read 1 RU, Strong 2x, insert about 5.5 RU, replace about 2x insert). It asks only for the lowest and the highest operation.
- Reading the TTL docs, `0` is not a valid default TTL (a nonzero value is required). It is used as a wrong option in `dp420-1a-mgmt-dotnet-create`.
