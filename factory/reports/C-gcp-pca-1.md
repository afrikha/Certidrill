## Doubts and deviations
- **Gemini Cloud Assist is Preview.** Its overview and setup pages label the whole offering Preview (Pre-GA terms) in November 2026, yet the exam guide lists it twice (1.2.6, 5.1.5). The chapter teaches what it does, setup roles and APIs, and the data residency/CMEK caution, and says it is Preview. Question writers should test capabilities and the residency caution, never "enable it in production" as a correct answer. Investigations: since April 10, 2026, creating them requires Premium Support or account-team access (investigations page); the pricing page instead ties them to Gemini Code Assist Enterprise. The chapter states both.
- **Spot VM notice.** The profile says "30 s notice". The current Spot page says the preemption notice is 0 s (default) or 120 s (configurable), followed by a best-effort shutdown of up to 30 s. My chapters only say "preempted at any time, no SLA"; the profile line may need an update. Launch stage of the 120 s option was not checked.
- **Renames found that the profile does not list**: Log Analytics → Observability Analytics (June 2026 blog); Dataproc on Compute Engine and Serverless for Apache Spark → Managed Service for Apache Spark; GKE node auto-provisioning → node pool auto-creation (`--enable-autoprovisioning` flag unchanged). Listed in the 00 rename table. Later chapters (Dataproc in 1.3.4/2.2.2, Observability in 6.x) should use these names.
- **Spend cap budgets**: the budgets page mentions "spend cap budgets" that pause services when exceeded. Launch stage and supported services were not on the fetched part, so the chapter only states that an alerts-only budget doesn't cap spend.
- **API Gateway OpenAPI version**: overview says OpenAPI 2.0; navigation shows OpenAPI 3.x pages. The chapter says "an OpenAPI specification" without a version.
- **Multi-select scoring**: Google publishes no partial-credit rule; the chapter says Certidrill scores all or nothing (as in blueprint.yaml).
- **DR pattern examples**: Google's DR planning guide names cold/warm/hot with an analogy and no product mapping; the product examples in the table of 11 are my mapping from the Cloud SQL DR, disk replication and global load balancing pages.
- Prices were left out on purpose (BigQuery, egress), except Spot "up to 91 %", CUD maximums and the 5 % custom machine type premium.
