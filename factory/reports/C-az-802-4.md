## Points to review

- **Azure Files management models (new in 2026)**: chapter 51 states that `Microsoft.FileShares` file shares are NFS-only, provisioned v2, LRS/ZRS, with no Azure File Sync (files-management-concepts, 2026-10-27), so every Windows Server/SMB scenario uses classic shares in a storage account. Provisioned v2 limits (32 GiB to 256 TiB, 50 shares per account), portal default "Require Encryption in Transit for SMB" = selected, and soft delete 7 days (1-365) come from create-classic-file-share (2026-10-26).
- **SMB signing defaults**: Learn is inconsistent. smb-security-hardening (2024-10) says inbound and outbound signing are required by default; smb-signing (2025-08) and what's-new-WS2025 say Windows Server 2025 requires **outbound** signing only. The chapter follows the newer pages (outbound only; DCs require inbound).
- **NTFS maximum volume size**: refs-overview's comparison table still says NTFS 256 TB; ntfs-overview says 8 PB on Windows Server 2019+ with 2048 KB clusters. Chapter 54 uses 8 PB.
- **ReFS boot** is mentioned only as "preview" (refs-boot article, Insider builds); the chapter keeps "ReFS isn't bootable" as the exam answer.
- **Storage Replica**: the overview says the log size defaults to 8 GB and the log volume must be at least 10 GB; the chapter states both. The overview names a `Test-Failover` cmdlet; the chapter describes "test failover" without a cmdlet name (did not verify `Mount-SRDestination`). Compression is listed in what's-new-WS2025 but the overview restricts it to Azure Edition; the chapter leaves compression out.
- **S2D single parity efficiency** not found on Learn: the table says "Higher than three-way mirror" rather than a number. S2D overview lists Datacenter editions only up to 2022; the deploy article says Datacenter is required (used).
- **Written from knowledge, not re-read on Learn** (standard cmdlets/feature names): `FS-Resource-Manager`, `FS-DFS-Replication`, `FS-iSCSITarget-Server`, `Multipath-IO`, `Enable-MSDSMAutomaticClaim`, `New-IscsiTargetPortal`, `Add-IscsiVirtualDiskTargetMapping`, `New-DfsnFolder`, `Grant-SmbShareAccess -AccessRight`, `Set-Disk -IsOffline`, `Resize-Partition`/`Get-PartitionSupportedSize`, `New-VHD`/`Mount-VHD`, `Add-PhysicalDisk -Usage HotSpare`, `Set-PhysicalDisk -Usage Retired`, `Repair-VirtualDisk`, `Suspend-ClusterNode -Drain`, `Get-StorageJob`, `Get-NetAdapterRdma`, `Get-SmbMultichannelConnection`, `Enable-BitLockerAutoUnlock`, `Suspend-BitLocker -RebootCount`, `Format-Volume -SetIntegrityStreams`, `manage-bde -unlock/-status`. Also: DFS-N referral ordering by site cost, FSRM quotas vs NTFS disk quotas, the GPO option that blocks BitLocker until recovery info is stored in AD DS, and the iSCSI Initiator "Configuration" tab.
