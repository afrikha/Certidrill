## Course discrepancies found (chapter 44-monitoring-optimization, not edited)

- The 4.4.6 table lists `DatabricksTables` ("table creation, deletion, access, permission changes"). No such table exists in the Azure Monitor list of supported log categories for Microsoft.Databricks/workspaces. Unity Catalog events go to `DatabricksUnityCatalog` (category `unityCatalog`). The questions use `DatabricksUnityCatalog`.
- The chapter shows `VACUUM ... RETAIN 336 HOURS`. The current VACUUM SQL reference and the "Remove unused data files with vacuum" page no longer document `RETAIN`. They say that in Databricks Runtime 18.0 and above, retention is controlled by the `deletedFileRetentionDuration` table property. The questions avoid `RETAIN` and use `delta.deletedFileRetentionDuration`.
- In the clusters audit events, `delete` means the cluster was *terminated* and `permanentDelete` means it was deleted. The chapter doesn't say this; dp750-4d-kql-cluster-deletes and dp750-4d-alert-prereqs test it.
