## Facts I used without seeing them stated on a page (well established, but please review)

- When the allow filter list is enabled, only the listed MAC addresses get leases (az802-4b-dhcp-mac-allow-list). Learn only says that `-Allow` "specifies the enabled state" of the list.
- Without a superscope, relayed requests for the floor are answered only from the scope that matches the relay's primary address (az802-4b-superscope). Learn's wording is that superscopes let the server lease across several logical subnets on one physical network.
- A superscope isn't an option level (az802-4b-option-levels, a distractor). Learn lists server, scope, reservation and policy as option levels.
- Clients receive changed options only when they renew (az802-4b-option-change-renewal). The 50 % renewal and 87.5 % rebind timers are on Learn.
- Clustered DHCP as an HA solution on its own (az802-4b-ha-options). Learn only describes clustered DHCP together with failover.
- When a scope is added to an existing relationship with Add-DhcpServerv4FailoverScope, its configuration (including exclusions) is copied to the partner (az802-4b-failover-add-scope). Learn says the scope must not exist on the partner, and that settings are replicated when failover is first configured.

## Points to review

- **Learn contradiction on `-ServerRole`**: the Add-DhcpServerv4Failover reference (parameter text and example 2) says `-ComputerName X -ServerRole Standby` makes X the standby server. The "Manage DHCP failover relationships" page says the same command makes the *partner* the standby. None of my questions depends on it. The cs2a case question uses `-ServerRole`, so it is worth checking.
- The "31 failover relationships per server" limit is in the Learn source repository. The fetched page summary didn't show it, so I left it out.
- **French**: no AZ-802 glossary exists. I used the terms of chapter 42 (FR): « étendue », « plage d'exclusion », « réservation », « superétendue », « agent de relais », « relation de basculement », « équilibrage de charge », « secours à chaud », « partenaire indisponible ». I didn't see « superétendue » or « étendue fractionnée » (split scope) on a fetched fr-fr page. Wizard and checkbox names are kept in English (Configure Failover, Enable Message Authentication).
