## Facts verified on learn.microsoft.com (2026-11-17) worth a reviewer's eye

- Host pool management approach (standard vs session host configuration) is fixed at creation; session host configuration = pooled only; Virtual Machine User Login is needed only for host pools without a session host configuration.
- Registration token lifetime up to 27 days; machine token lost after 90 days powered off; up to 400 VMs per deployment; name prefix 11 chars, full name 15.
- Hibernate: personal pools only, not with FSLogix or App attach.
- Scheduled agent updates: 1–2 windows of 2 hours, only on existing pools, forced after 4 failures.
- Session host update: management policy defaults (batch 1, logoff delay 2 min, 0–60), disable autoscale, no cross-subscription gallery images.
- Licensing table (eligible licenses; Windows Server 2016–2025 RDS CAL with SA; no per-user access pricing for Windows Server); RDS CAL grace 120 days; GPO names and path.
- Image Builder: buildTimeoutInMinutes default 240, max 960; File customizer under 20 MB; user-assigned identity required. Custom image template prerequisites, resource providers and custom role actions.
- Compute Gallery: up to 100 replicas per version, 1 per 20 concurrent VMs, at least 3 for production; new definitions default to V2 + TrustedLaunchSupported; Trusted launch doesn't support managed images.
- Conditional Access app IDs (Azure Virtual Desktop 9cdead84…, Windows Cloud Login 270efc09…), don't target the ARM Provider app, "Every time" only on Windows Cloud Login with SSO.
- SSO not supported on hosts joined only to AD DS or Entra Domain Services; up to 10 device groups; consent remembered for 15 hosts / 30 days.
- External identities requirements (Windows 11 24H2 + KB5065789 or Windows Server 2025 + KB5073379); written without KB numbers in the chapter.
- Defender AV VDI settings, FSLogix exclusions list, MDE VDI onboarding models, required session host endpoints, Azure Firewall guidance (route WindowsVirtualDesktop service tag to Internet, no TLS inspection), JIT (Plan 2, 3389, 3 h, permissions), Controlled folder access modes, confidential VM sizes and limitations.
