## Sources and notes

- No DP-750 course chapters existed yet when this batch was written. Facts come from Microsoft Learn (Azure Databricks docs) and from the training module "Govern Unity Catalog objects" (units 3 to 7), fetched on 2026-11-17.
- **Delta Sharing renamed OpenSharing.** Learn now documents Delta Sharing as "OpenSharing", with pages under `/azure/databricks/opensharing/`. The study guide and the training module still say "Delta Sharing", so the stems use "Delta Sharing". References point to the current OpenSharing page titles. The course chapter for 2.2.7 should mention both names.
- ABAC: the metastore-level policies, policies on views, and DENY/GRANT policies are Beta, so the questions leave them out. Only catalog, schema and table policies on tables are tested. Runtime requirement used: serverless, or DBR 16.4+ on standard/dedicated compute (dedicated also needs FGAC).
- Retention: the questions leave out auto-TTL (`DELETE ROWS n DAYS AFTER`, DBR 17.3+) because I could not confirm its release status (preview or GA). The configurable retention period of system tables (Beta) and the ALTER CATALOG/SCHEMA setting for the UNDROP window are left out as well.
- Audit: the retention used is 395 days for `system.access.audit`. The training module rounds it to "one year", and the system table is in Public Preview. The Log Analytics table names come from the Azure Monitor supported-logs reference.
- Lineage: retention is indefinite in Catalog Explorer and the lineage API for events since 2024-09-01, and a rolling one-year window (395 days) in the system tables.
- The training unit on audit logging says diagnostic delivery is set up "at the account level". The product doc says it is set on the workspace resource (Monitoring > Diagnostic settings, Premium plan). The questions follow the product doc.
