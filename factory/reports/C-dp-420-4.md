## Conflicts between Learn pages

- String size: the Cosmos DB in Fabric limitations and FAQ pages say JSON strings over 8 KB are truncated in the SQL analytics endpoint; the mirroring limitations page says tables created after 2025-11-18 use `varchar(max)` up to 2 MB. The chapter states the mirroring-page rule.
- Mirror source region: overview and limitations say the write region; the FAQ says the closest region (for egress). The chapter says the write region.
- Private endpoints: the FAQ lists them as not supported; the overview and the private-network page document a supported setup. The chapter follows the private-network page.
