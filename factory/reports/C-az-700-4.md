## Points to review

- **Load Balancer idle timeout**: written as 4 to 100 minutes for load-balancing and inbound NAT rules (articles load-balancer-tcp-idle-timeout dated 2026-08-05 and load-balancer-tcp-reset). The `az network lb rule create` help still says 4 to 30. Outbound rules: 4 to 120.
- **Naming**: Learn now titles the cross-region load balancer "Global load balancer" (Global tier). The chapters use both names.
- **Inbound NAT pools**: retirement September 30, 2027, and no new pools since November 15, 2026 (inbound-nat-rules dated 2026-01-07 and whats-new).
- **Application Gateway**: v1 retired April 28, 2026; Basic SKU still preview (overview-v2); advanced routing rules preview (mentioned once as preview); HTTP/3 preview left out. Private deployment (`EnableApplicationGatewayNetworkIsolation`) written as generally available, as the article states.
- **Autoscale ranges**: minimum 0 to 100, maximum up to 125 (default 10), manual 1 to 125, as the autoscaling article states.
- **Traffic Manager Linked Records** (Azure DNS article dated 2026-10-05) cited as the recommended apex option, with alias records.
- **CLI defaults**: `az network application-gateway probe create` documents defaults (interval 30, timeout 120, threshold 8) that differ from the default probe (30/30/3); the chapter example passes explicit values. Not explained in the chapter.
- **Not verified on Learn samples**: the rewrite condition variable spelling `var_ssl_enabled` in the CLI example (the CLI page only says values come from `list-server-variables`); `az network application-gateway rule update --rewrite-rule-set` exists per the CLI page but has no example there.
- **Home regions** of the global load balancer: a subset of Learn's list is given as examples.
- **Left out because not verified**: whether an internal load balancer private frontend can be dynamic, Application Gateway for Containers, Front Door specifics (other chapter), WAF policy details (other chapter if any).
