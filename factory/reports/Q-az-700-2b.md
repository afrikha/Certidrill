## Points to review

- **Course chapter 24, route filters**: the chapter gives "Azure Storage in West Europe" as an example of a route filter community. The routing requirements page lists *regional* communities (12076:51xxx) for Azure services and *service* communities only for Microsoft 365, Microsoft Entra ID, Azure Resource Manager and similar. The questions use regional communities (`er-msft-no-routes`, `er-routefilter-order`, `er-peering-statements`). The course author should check that example.
- **Reserved ASNs**: the routing requirements page reserves 65515–65520, but the routing-arm page forbids only 65515 as the peer ASN. No question depends on this.
- **ECMP circuit count**: the FAQ says ECMP load-balances across at most 4 circuits, but the disaster recovery page says up to 16. No question uses either number.
- **Azure public peering** is a distractor in `er-peering-match` (item) and `er-private-ps` (enum value `AzurePublicPeering`). The archived Learn page says it is deprecated, can't be created on new circuits, and was scheduled for retirement on March 31, 2024.
- **ExpressRoute Local versus Standard unlimited cost** (`er-sku-local`): no pricing page was fetched. The answer relies on the FAQ, which says the Local price includes egress, and on Local's positioning as the low-cost SKU for the nearby region. The scenario is a large, steady egress volume to the local region.
- **P2S and Private Resolver** (`p2s-private-dns`): the troubleshooting page says the gateway pushes the virtual network's custom DNS server to clients. The explanation adds that clients need the updated client configuration, which is consistent with chapter 22.
- **Entra ID access by group** (`entra-group-access`): Learn says one custom app per gateway, with Assignment required. The distractor "Conditional Access on the Azure VPN application" is wrong because both gateways share the Microsoft-registered app. Learn doesn't explicitly say Conditional Access can't be scoped per gateway in that case.
- **Left out because not verified**: the Local SKU bandwidth options, the semantics of `-RadiusServerScore` (higher or lower wins), and the French portal labels of the Entra ID fields (kept in English as Tenant, Audience, Issuer, like the course).
