## Facts not seen on a fetched page (general knowledge, flag for review)

- `fDenyTSConnections` = 0 and `Enable-NetFirewallRule -DisplayGroup "Remote Desktop"` to enable RDP (az802-2a-rdp-enable-remote). The course chapter uses the same commands.
- Administrative Templates categories of "Allow delegating fresh credentials", the NLA setting and "Allow users to connect remotely by using Remote Desktop Services" (hotarea az802-2a-rdp-delegation-policies). The two Credentials Delegation settings that hold the answers were confirmed on the Remote Credential Guard page.
- `Virtual Machine Administrator Login` used for Entra sign-in to VMs (a distractor), and `Distributed COM Users` / `Remote Management Users` purposes (distractors).
- `extensions.allowlist` as an azcmagent config key (distractor only; `proxy.url`, `proxy.bypass` and `incomingconnections.ports` were seen on fetched sources).
- az802-2a-arc-cloned-429 option a: that plain `azcmagent disconnect` on the clones fails once the shared resource is deleted. This is inferred from the azcmagent disconnect page, which says to use `--force-local-only` when the resource is already deleted.
