- Exam: 100 minutes, proctored, "may have interactive components", languages EN/JA/ZH-Hans/FR/DE/ES/PT-BR, retake after 24 h, renewal yearly; Learn access documented only for associate/expert role-based exams (same wording as the AZ-140 intro).
- SAP Note 2015553 (training unit "Explore licensing, pricing, and support"): Professional Direct = minimum; "Microsoft Premier Support" recommended for Windows/SQL Server. Support plan list and response times from azure.microsoft.com/support/plans (not Learn).
- HANA Large Instances in sunset (no new customers); Azure VMware Solution generally not supported by SAP; Entra ID not supported as domain for SAP on Windows (Entra Domain Services "still in testing").
- Storage matrix, Write Accelerator mandatory for /hana/log on Premium SSD (M/Mv2), Premium SSD v2 / Ultra not with availability sets, LRS only for DB files (planning-guide-storage).
- Capacity reservation: not supported with availability sets, PPGs, Ultra Disk, M-series v1, Msv3 HM, Mdsv3 HM/VHM; Free Trial / Azure for Students not eligible.
- ACSS roles (administrator, reader, service role) and UAMI roles (Managed Identity Operator / Contributor, Reader and Data Access).
- SAP Cloud Identity Services SCIM 2.0 connector GA on 2025-09-30 (groups need Entra ID P1, System-type admin, ~40 min cycles).
- RISE: ACSS and Azure Monitor for SAP solutions not supported with RISE; Azure DNS / private zones don't support zone transfer; SAP's dedicated ER/VPN reaches only the SAP VNet; SAP IDM retirement by 2027; RISE infra/OS logs only via SAP LogServ.
- Note: the CAF SAP landing zone pages (enterprise-scale-landing-zone, eslz-identity-and-access-management, migrate) are marked deprecated with removal on 2026-10-30, but still served; 1.2.6 content relies on them.
