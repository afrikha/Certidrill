## Doubts and choices to review

- **Bastion SKUs** (`bastion-sku-table`, `bastion-shareable-link`): the Learn unit now describes the four tiers and the connection methods, so two questions test them. This may be more detail than the exam asks; the unit says "tiers", the docs and the course say "SKU" (used here).
- **Bastion and peering** (`bastion-peering-scope`): the stem states the Standard SKU because the Developer SKU does not support peered virtual networks (SKU comparison page).
- **NSG on AzureBastionSubnet**: the Learn unit says no NSG has to be applied to the Bastion subnet; no question relies on it.
- **Foundational CSPM "enabled by default"** (`cspm-plans-complete`, `cspm-basics-yn`): from the Learn unit. The docs page `security-policy-concept` says the Defender portal experience has no free Foundational CSPM plan (single paid Defender CSPM plan there). Questions follow the Learn unit and the CSPM plans page.
- **Regulatory compliance and plans**: the CSPM plan table marks "Regulatory compliance assessments" as Defender CSPM only, the Learn unit puts MCSB compliance in Foundational CSPM. No question depends on which plan is needed to add a regulatory standard (`pol-compliance-dashboard` only names the dashboard).
- **Secure score** : the Learn unit and the docs word differently when the score improves (all recommendations of a control for a resource / for all resources), and the docs now describe two models (classic score in the Azure portal, risk-based Cloud Secure Score in the Defender portal). No question on the calculation; "Microsoft Secure Score" is never used as a distractor because the docs now present it as a family that includes the cloud score.
- **DSPM with Defender for Storage** (`cspm-plans-complete`, third list): stated in the Learn unit and the introduction page; possibly fine detail for SC-900.
- **Just-in-time VM access** (`cwp-jit-access`, distractor in `bastion-remove-public-ip`): the docs title is "Just-in-time machine access" and place it in Defender for Servers Plan 2; the questions use the Learn unit's wording "just-in-time VM access" and do not name the plan number in the stem.
- **Custom standards** (`pol-custom-standard`): custom recommendations inside a custom standard require the Defender CSPM plan (docs); the question does not go into that.
- **AI security** (`mdc-ai-yn`, one option of `cspm-outcome`, `cspm-capabilities-match`): present in the Learn units and in course chapter 32; the outline has no dedicated AI objective.
