## Doubts and deviations

1. **Gemini Cloud Assist (1.2.6) is Preview.** The overview and setup pages call Gemini Cloud Assist "this Preview offering" under Pre-GA terms. Investigations are Preview too, and since 10 April 2026 creating or running one needs a Premium Support contract or access through the account team. The brief says a Preview feature is never the correct answer, but this objective is about Gemini Cloud Assist itself. So the 4 questions test what its capabilities do and how to set it up (Application Design Center, investigations, IAM roles, exempting projects from a folder with `gcp.restrictServiceUsage`). They never pick it over a GA alternative. The investigation question states that the organization has access to investigations. A reviewer should confirm that this is acceptable.
2. **Log Analytics is now Observability Analytics.** The Cloud Logging page title and text now use "Observability Analytics" (the URL is still `/logging/docs/log-analytics`). The questions use the new name. Other batches and the course should use it too.
3. **Vertex AI names.** The questions use the names from the official mapping page (`/gemini-enterprise-agent-platform/vertex-ai-name-changes`): Gemini Enterprise Agent Platform, Agent Search (formerly Vertex AI Search), Model Garden, Agent Platform endpoints, Provisioned Throughput, and Model Armor (unchanged). The doc URLs still contain `vertex-ai`.
4. **Spanner dual-region question (gcppca-1b-spanner-dual-region-zero-rpo).** The stem does not name a country, so that the question does not depend on which countries have a dual-region configuration. It says the needed configurations are available. Dual-region and multi-region configurations need the Enterprise Plus edition, which the correct option says.
5. **Things I could not verify, so they are left out:** the minimum soft delete duration in Cloud Storage (the page seemed to say 3–90 days, I expected 7–90), how many VMs a compact placement policy allows, which machine series support Hyperdisk Balanced (the questions use N4 or say "a series that supports Hyperdisk"), and the launch stage of Model Armor and Provisioned Throughput (neither page has a Preview label).
6. **Global load balancer failover between regions** (gcppca-1b-global-alb-multi-region-failover, gcppca-1b-global-users-cdn-multi-region). The fact that a global external Application Load Balancer sends traffic to the next region when the closest one has no healthy backend is standard load balancing behavior. The fetched "Choose a load balancer" page backs it only indirectly (global load balancers serve backends in several regions). A more specific page could be added as a reference during review.
