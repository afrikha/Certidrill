## Points to review

- 5.2.1 (`share-local-vs-network`, `share-effective-statements`) cite `Share and NTFS Permissions on a File Server` (previous-versions, Windows Server 2008 R2 docs): no current Learn page on share vs NTFS combination was found without search.
- Distractor facts from general knowledge, not re-read on a fetched page: point-in-time restore is for block blobs only (`files-previous-versions`); "Large file shares" raises the pay-as-you-go capacity limit (`files-port-445-blocked`); Data Box as the offline transfer option (`migrate-tool-choice`, the migration overview only lists it with full fidelity).
- The KDC proxy GPO name and the Lanman Workstation/Lanman Server "Enable SMB over QUIC" policies come from the smb-over-quic Markdown source; the WebFetch summary of the page did not show them.
- New on Learn (Nov. 2026), not tested and not in chapter 51: the role **Storage File Data SMB Take Ownership**, and "group-based access for non-synced AD DS users" (a user not synced to Entra ID gets the RBAC role of a synced AD DS group it belongs to). Chapter 51 says SMB Admin includes take ownership; it still does, but the course could mention both.
- `share-settings-hotarea` and `fsrm-screen-ps`: `-Active` is described on Learn as "enabled by default" while the parameter table says "None"; the question only asks for the blocking option, so the default does not decide the answer.
