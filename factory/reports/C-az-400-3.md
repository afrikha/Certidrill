## Recent facts verified on learn.microsoft.com / docs.github.com on 2026-11-17 (worth a reviewer's eye)

- **Azure DevOps public projects retired**: no new public projects; existing ones convert to private in 2027 (concurrent-jobs page). Written as an exam tip in 33.
- **Azure Deployment Environments retires on 22 February 2027** (overview and key concepts pages). It is still objective 3.5.5 of the July 2026 guide, so the chapter covers it with the retirement notice. Question writers should be aware.
- **Azure Automation State Configuration retires on 30 September 2027**; Linux DSC retired 2023.
- Microsoft-hosted agents: `windows-latest` = Windows Server 2025 (VS 2022), `windows-2025-vs2026` GA 2026-09-29 and `windows-latest` will move to it "in the coming weeks"; Windows Server 2019 image retired 2025-12-31. Standard_DS2_v2, 10 GB free disk. Azure Pipelines can now also use "GitHub-hosted agents" (pay-as-you-go) — not written in the chapter.
- Parallel jobs: free hosted grant 1 job, 60 min/run, 1,800 min/month; paid 360 min/job; new organizations capped at 25 hosted parallel jobs.
- Managed DevOps Pools: VMs in a Microsoft subscription, jobs up to two days, state up to seven days, billed as Azure resources plus self-hosted parallel jobs.
- Since Sprint 229, fork PRs aren't built automatically by Azure Pipelines.
- GitHub limits: 6 h hosted job, 5 days self-hosted job, 35-day run, 256 matrix jobs, 24 h self-hosted queue; concurrency 20/40/60/500 (macOS 5/50); reusable workflows 10 levels, 50 unique per file; environment wait timer 43,200 min, 6 reviewers; required reviewers and wait timers only for public repos on Free/Pro/Team.
- GitHub artifacts/logs retention: default 90 days, 1–90 public, 1–400 private. Caches: 7 days unused, 10 GB per repo default.
- App Configuration: Operations > Feature manager; prefix `.appconfig.featureflag/`; built-in filters `Microsoft.Percentage`, `Microsoft.TimeWindow`, `Microsoft.Targeting`; `requirement_type` Any (default) / All; feature flag refresh 30 s by default.
- App Service: slots in Standard (5), Premium and Isolated (20); auto swap not supported on Linux / Web App for Containers.
- Machine Configuration: modes Audit / Apply and Monitor / Apply and Autocorrect, max 50 guest assignments per machine, VMSS Uniform not supported.
