## Points for the reviewer

- **Reference titles.** For docs pages whose `<title>` and H1 differ, the `<title>` is used (e.g. "Azure DDoS Protection Overview", H1 "What is Azure DDoS Protection?"; "Introduction to Azure Web Application Firewall", H1 "What is Azure Web Application Firewall?"). Training units use the unit title without "- Training".
- **IDPS tier.** The training unit "Describe Azure Firewall" says in its Security Copilot paragraph that IDPS is "available in Standard and Premium SKUs"; the Azure Firewall overview, the SKU comparison and the rest of the same unit give IDPS to Premium only. The questions follow Premium (`fw-tiers-yn`, `fw-stateful` explanation).
- **Default outbound access.** No question relies on "a VM can reach the internet by default" (feature being changed); outbound behaviour is only tested through the NSG default rule AllowInternetOutBound.
