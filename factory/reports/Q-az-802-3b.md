## Points to review

- **SR-IOV only at switch creation** (az802-3b-vswitch-sriov): inferred from the cmdlet references. `-EnableIov` exists on `New-VMSwitch`, and `Set-VMSwitch` has no IOV parameter. No Learn sentence that says so explicitly was found.
- **Disk type change requires deallocation** (az802-3b-azdisk-facts s3): disks-convert-types says that "conversion requires a restart" and that every example deallocates first. That isn't an explicit "must".
- **Guest teaming** (az802-3b-team-guest): the scenario was changed so that both VM adapters are on the same switch. The `-AllowTeaming` reference says "teamed with other network adapters connected to the same virtual switch". Older guidance (one adapter per external switch) wasn't used.
- **DeviceNaming** is described as "exposes the adapter name to the guest". The cmdlet page gives no detail beyond "uses device naming".
- **Extended replication**: 5 or 15 minutes only, no 30 seconds (replication-virtual-machines, 2026-04-28).
- **Left out because not verified**: the 99.99 % SLA for VMs across zones, which was removed from az802-3b-avail-zones-datacenter (only 99.95 % for availability sets was found). Also left out: whether `Add-VMSwitchTeamMember` works on a non-SET switch, and the default value of `New-VMSwitch -AllowManagementOS`. A first draft of the external-switch dropdown was dropped for that last reason and replaced with a NAT switch dropdown.
- **French**: terms not seen on a fetched fr-fr page: « période de refroidissement (cool down) », « stratégie de scale-in », « groupe de placement de proximité », « mise en réseau accélérée », « transfert IP », « usurpation d'adresses MAC », « protection DHCP ». They are worth checking for a future AZ-802 glossary.
- **Overlap with case-study questions**: the Bastion SKU dragdrop uses Premium for "no public IP" and Standard for the native client, while az802-cs1c-bastion-sku tests Premium for recording and az802-cs3b-bastion-native tests the native client. The scenarios and decisions differ, but a reviewer may want to compare them.
