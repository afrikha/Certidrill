## Doubts and deviations
- Docs disagree on offline copy for NoSQL: the concept page lists offline copy only for MongoDB and Cassandra, while the how-to page still has a NoSQL "Offline container copy" tab (`az cosmosdb copy create` without `--mode`). No question depends on NoSQL offline copy.
- The how-to page is titled "Intra-account" but documents cross-account copies (source identity + data-plane role `...0002` on the destination). `dp420-1e-copy-cross-account` relies on that how-to section.
- Learn has two install commands for Agent Kit: `npx skills add AzureCosmosDB/cosmosdb-agent-kit` (Agent Kit setup/overview) and `npx add-skill AzureCosmosDB/cosmosdb-agent-kit` (GitHub Copilot best-practices page). Questions use only the first; the second is not offered as a distractor.
- Vector index mutability differs between pages (vector-search: drop and re-add the policy/index; hybrid-search: create a new container). Not tested.
- The hybrid-search page shows `SELECT TOP @k`, while an Agent Kit rule (dev blog) says TOP must be a literal. Questions use literal TOP only.
- Projection lowering RU is from Agent Kit guidance (usage page: "unnecessary projections"); Optimize Request Cost does not state it, so the explanations say "can lower the RU charge".
- The French Learn page for container copy uses « travail de copie »; questions use « tâche de copie de conteneur » as in the official study guide (objectives.yaml).
