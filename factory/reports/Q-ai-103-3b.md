## Doubts to review

- **Pro mode (3.2.7)**: documented only in What's new (May 2025, `2025-05-01-preview`: reasoning, multiple input documents, external knowledge base, documents only, standard is default). Whether pro mode still exists in the GA API is not stated. `pro-mode-crosscheck` and `pro-mode-facts` depend on it.
- **`cu-rest-order`**: the PUT `/contentunderstanding/analyzers/{id}` create call comes from the course chapter; the fetched quickstart shows only analyze and get-result.
- **`inject-approval`** and the OCR-then-shield pipeline in `inject-pipeline`: design built from documented pieces (Prompt Shields analyzes text documents); no Learn page covers injection through images or human approval of function calls specifically.
- **Guardrails on image inputs** (`filter-chat-guardrail`): the classic content-filter page has an "Image content filters" section citing the four categories; its details were not readable.
- **`objects-code`**: `json_object` (distractor) and `"text"` as Responses `text.format` types are not shown on a fetched page.
- **`cu-routing`**: the analyzer reference says each category has a required `description` but its own example uses `"other": {}`; the question gives every category a description. The `enableSegment` slot has only two options (true/false).
- **`cu-field-methods`**: dragdrop with 3 items (only three field methods exist), below the guide's 4–6.
