# AIP-C01 exam profile

- **Format** (guide without version or date, checked 2026-11-19; beta closed March 31, 2026, standard exam since): 180 minutes, 75 questions (65 scored + 10 unscored), scaled 100–1,000, pass **750**, compensatory, no guessing penalty. Domains: foundation 31 %, implementation 26 %, safety 20 %, operations 12 %, testing 11 %. English, Japanese, Korean, Simplified Chinese (no French). Mock: all 75 scored (about 2 min 20 s per question).
- **Level**: professional GenAI developer (2+ years building production apps, 1 year of GenAI). Out of scope: model development and training, advanced ML techniques, data and feature engineering.
- **Types**: `single` 4 options (about 83 %); `multi` 5 options / 2 correct ("Choose two.") or 6 / 3 ("Choose three."), about 17 %, all or nothing. No ordering, matching or case study.
- **Stems**: 3–7 sentences: a company, its GenAI application (assistant, RAG search, document pipeline, agent), its data, users and constraints on latency, cost, accuracy, safety or compliance, then a qualifier ("LEAST operational overhead", "MOST cost-effective", "lowest latency", "without changing application code", "MOST secure"), then "Which solution will meet these requirements?". Options are complete designs; distractors are valid AWS designs that miss one stated constraint. Hard = the qualifier or one feature limit decides.
- **Traps**: Bedrock model choice, cross-Region inference profiles (geographic vs global) vs Provisioned Throughput vs on-demand vs batch inference; prompt management, prompt caching, Prompt Flows; Knowledge Bases: chunking, embedding dimensions, vector stores (OpenSearch Serverless, Aurora pgvector, S3 Vectors: float embeddings only), metadata filtering, reranking, hybrid search; agents: AgentCore and Strands Agents vs Bedrock Agents Classic, MCP servers on Lambda or ECS, Step Functions for approvals and stopping conditions; fine-tuning vs continued pre-training vs distillation vs RAG, LoRA on SageMaker AI; Guardrails (content filters, prompt attacks, denied topics, PII, contextual grounding, Automated Reasoning checks); evaluation (Bedrock model and RAG evaluation, LLM-as-a-judge, human review); security (IAM, VPC endpoints, KMS, prompt injection); monitoring (CloudWatch, model invocation logging, X-Ray, cost anomalies); SageMaker AI endpoints for custom models.
- **Closures and renames (verified on AWS pages, November 2026)**: closed to new customers since July 30, 2026: **Bedrock Agents Classic** (successor AgentCore; Knowledge Bases and Guardrails unaffected), **Kendra**, **Q Business**, SageMaker AI **Clarify**, **Model Monitor**, **Ground Truth**, **A2I**. **Q Developer**: sign-ups closed May 15, 2026, IDE plugins end of support April 30, 2027, successor **Kiro**. AWS Chatbot is now Amazon Q Developer in chat applications; QuickSight became **AWS Quick**; Data Wrangler is integrated into SageMaker Canvas; App Runner in maintenance. Never make a closed service the right answer for a new design.
