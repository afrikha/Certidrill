# SAA-C03 exam profile

- **Format** (exam guide v1.1, October 29, 2026; certification page checked 2026-11-19): 130 minutes, 65 questions (50 scored + 15 unscored, not identified), scaled score 100–1,000, pass at 720, compensatory scoring (no per-domain pass). Domains: secure 30 %, resilient 26 %, performance 24 %, cost 20 %. Our mock exam scores all 65.
- **Level**: associate design exam (one year of hands-on AWS design). The candidate picks the service, feature, storage class, instance family, purchasing option or topology that meets every stated requirement. No CLI syntax to recall, no console click path, no code to write.
- **Types**: `single`: 4 options, 1 correct (78–88 %); `multi` 5 options with 2 correct ("Choose two.") or 6 options with 3 correct ("Choose three."), about 12–22 %. No case study, no Yes/No series, no drop-down, no drag and drop.
- **Stems**: 2–5 sentences. A company ("A media company", "AnyCompany", "Example Corp"), its current architecture, the requirements, then a deciding qualifier: "with the LEAST operational overhead", "MOST cost-effective", "with the highest availability", "with the least latency", "without changing the application code", "MOST secure", "with minimal downtime". Then "Which solution will meet these requirements?". Options are complete one- or two-sentence AWS designs; each distractor fails one stated requirement, often the qualifier (works but costs more, needs more management, or changes code).
- **Classic traps**: S3 storage class minimum storage durations and retrieval fees (Standard-IA, One Zone-IA, Glacier Instant/Flexible Retrieval, Deep Archive), Intelligent-Tiering for unknown access patterns; RDS Multi-AZ (availability) vs read replicas (read scaling, cross-Region DR); Aurora Global Database; NAT gateway per AZ vs one shared NAT gateway; gateway endpoints (S3, DynamoDB, free) vs interface endpoints (PrivateLink, hourly cost); SQS vs SNS vs EventBridge vs Kinesis; Global Accelerator (TCP/UDP, static IPs) vs CloudFront (HTTP caching); ALB vs NLB vs GWLB; security groups (stateful) vs network ACLs (stateless); SCPs do not grant permissions; KMS key policies; Spot vs Reserved Instances vs Savings Plans; DR strategies by RPO/RTO; EBS gp3 vs io2 vs st1/sc1; EFS vs FSx family; DataSync vs Storage Gateway vs Transfer Family.
- **In-scope services (guide, non-exhaustive)**: Analytics: Athena, Data Exchange, Data Pipeline, EMR, Glue, Kinesis, Lake Formation, MSK, OpenSearch Service, Amazon Quick, Redshift. Application Integration: AppFlow, EventBridge, MQ, SNS, SQS, Step Functions. Cost Management: Budgets, Cost and Usage Report, Cost Explorer, Savings Plans. Compute: Batch, EC2, EC2 Auto Scaling, Elastic Beanstalk, Outposts, Serverless Application Repository, VMware Cloud on AWS, Wavelength. Containers: ECR, ECS, ECS Anywhere, EKS, EKS Anywhere, EKS Distro. Database: Aurora, Aurora Serverless, DocumentDB, DynamoDB, ElastiCache, Keyspaces, Neptune, RDS, Redshift. Developer Tools: X-Ray. Front-End Web and Mobile: Amplify, API Gateway, Device Farm. Machine Learning: Comprehend, Lex, Polly, Rekognition, SageMaker AI, Textract, Transcribe, Translate. Management and Governance: AWS Auto Scaling, AWS CLI, CloudFormation, CloudTrail, CloudWatch, Compute Optimizer, Config, Control Tower, Health Dashboard, License Manager, Managed Grafana, Managed Service for Prometheus, Management Console, Organizations, Proton, Service Catalog, Systems Manager, Well-Architected Tool. Media: Kinesis Video Streams. Migration and Transfer: Application Discovery Service, Application Migration Service, DataSync, DMS, Snow Family, Transfer Family. Networking: Client VPN, CloudFront, Direct Connect, ELB, Global Accelerator, PrivateLink, Route 53, Site-to-Site VPN, Transit Gateway, VPC. Security: Artifact, ACM, CloudHSM, Cognito, Detective, Directory Service, Firewall Manager, GuardDuty, IAM Identity Center, Inspector, KMS, Macie, Network Firewall, RAM, Secrets Manager, Security Hub, Shield, WAF, IAM. Serverless: Fargate, Lambda. Storage: AWS Backup, EBS, EFS, FSx (all types), S3, S3 Glacier, Storage Gateway.
- **Out-of-scope services (guide)**: Amazon MWAA; Lightsail; RDS on VMware; AWS CDK, CloudShell, CodeArtifact, CodeBuild, CodeCommit, CodeDeploy, Corretto, Fault Injection Simulator, Tools and SDKs; Location Service; GameLift; all IoT services; Apache MXNet on AWS, Deep Learning AMIs, Deep Learning Containers, HealthLake, Inferentia, Personalize, PyTorch on AWS, TensorFlow on AWS; Console Mobile Application, Distro for OpenTelemetry; AWS Elemental (Appliances and Software, MediaConnect, MediaConvert, MediaLive, MediaPackage, MediaTailor), Amazon IVS; Migration Evaluator; Cloud Map; Braket; Ground Station. Elastic Transcoder was removed from the in-scope list in v1.1.
- **Verify availability (November 2026)** before making a service the correct answer: several in-scope services are closed to new customers — AWS Data Pipeline (no new customers), AWS Proton (support ended October 7, 2026), Snow Family devices (no new orders; DataSync / Data Transfer Terminal instead), Amazon Glacier vaults and Application Discovery Service (maintenance since November 7, 2025). The S3 Glacier storage classes inside S3 are not affected. Never make a retired service the right answer.
- Difficulty: 30 % easy, 50 % medium, 20 % hard (hard = two valid designs separated only by the qualifier, or three competing requirements).
