# DP-800 exam profile

- **Exam created in 2026** (SQL AI Developer Associate). Fetch every fact from Microsoft Learn before writing: syntax of the recent T-SQL functions (JSON, REGEXP_*, EDIT_DISTANCE, VECTOR_*), external models, vector indexes, Data API builder configuration, SQL Database Projects, change event streaming, and which platform supports what (SQL Server, Azure SQL, SQL database in Microsoft Fabric). Leave out what you cannot verify.
- **Study guide version**: the English page says March 12, 2026; the French page shows an October 19, 2026 version with minor changes. Follow `content/dp-800/objectives.yaml`.
- 120 minutes, pass at 700/1000, 45–58 questions in the simulator (Microsoft publishes no count); Learn announces no lab. The simulator adds one case study (4–6 questions) and one Yes/No series of 3.
- **Level**: associate, code-heavy. The candidate reads, completes and debugs T-SQL, Data API builder JSON and deployment pipeline YAML, and chooses a feature for stated constraints.
- **Stems**: 3–6 sentences with a table definition or a code excerpt, explicit constraints (least privilege, no application change, latency, cost), then "Which statement should you run?", "How should you complete the code?", "What should you recommend?".
- **Formats**: single choice (35–45 %), drop-down code completion (15–25 %), multiple choice (10–15 %), Yes/No statements (5–10 %), drag and drop of code fragments, ordering of deployment steps; hot area is rare.
- **Distractors and traps**: Always Encrypted vs column-level encryption vs Dynamic Data Masking vs Row-Level Security; CDC vs Change Tracking vs change event streaming vs triggers; isolation levels; full-text vs vector vs hybrid search; ANN vs ENN; REST vs GraphQL vs MCP endpoints; scalar vs table-valued functions.
- **Out of scope**: anything the study guide does not name (backup, high availability, migration, Azure Cosmos DB, model training).
- Difficulty: 30 % easy, 50 % medium, 20 % hard (hard = two constraints combined).
