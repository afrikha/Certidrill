# AZ-140 exam profile

- Specialty level. 100 minutes, pass at 700/1000, "may have interactive components". Formats are not published; the simulator uses 45–58 questions, one case study, one "does the solution meet the goal" series.
- **Candidate**: a desktop or server administrator who already knows Azure compute, networking, identity and storage (AZ-104 level is assumed, not re-tested). Infrastructure is 40–45 % of the exam.
- **Stems**: AZ-104 style, 3–6 sentences: "You have an Azure Virtual Desktop host pool named Pool1 that contains…", often a table of session hosts or users, one deciding constraint (join type, cost, least privilege), then "What should you configure / do first?". Hands-on: portal settings, RDP properties, FSLogix registry values, PowerShell and Azure CLI commands, Bicep or ARM fragments to complete.
- **Formats**: as AZ-104 — single choice (35–45 %); multi, Yes/No statements, drop-down (10–15 % each); drag and drop and ordering of deployment steps (5–10 % each); rare hot area.
- **Traps**: pooled vs personal host pools and their load-balancing or assignment options; desktop vs RemoteApp application groups; Microsoft Entra joined vs hybrid joined vs domain-joined session hosts and what each requires for FSLogix storage and single sign-on; RDP Shortpath for managed vs public networks; Profile Container vs ODFC container vs Cloud Cache; Azure Files vs Azure NetApp Files; Windows client per-user eligibility vs RDS CALs for Windows Server; autoscale vs Start VM on Connect; App attach vs installing in the image; Azure RBAC roles vs rights inside the session host.
- **Out of scope** (not named in the July 20, 2026 guide): Windows 365, third-party VDI brokers, on-premises RDS farm design.
- Difficulty: 30 % easy, 50 % medium, 20 % hard.
- Guide revised in July 2026 and the service evolves fast (RDP Multipath, App attach): fetch every limit, supported OS, role name, RDP property and cmdlet from Microsoft Learn.
