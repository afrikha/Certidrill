# Google Cloud Professional Cloud Architect — exam profile

- **Format** (cloud.google.com/learn/certification/cloud-architect, checked 2026-11-27): 2 hours, 50–60 questions, multiple choice and multiple select, English and Japanese (Certidrill: **English only**), 2 case studies per exam making up 20–30 % of the questions, shown on a split screen. Pass/fail only (no published score or pass mark). Recommended: 3+ years of industry experience, 1+ year on Google Cloud. Exam guide: services.google.com/fh/files/misc/professional_cloud_architect_exam_guide_english.pdf (6 sections ~25 / 17.5 / 17.5 / 15 / 12.5 / 12.5 %). Google's published case studies for the current exam: Altostrat Media, Cymbal Retail, EHR Healthcare, KnightMotives Automotive. Certidrill never reproduces them: its case studies are original.
- **Level**: professional, design-oriented. Most questions are scenarios where two or three options are technically valid and the stated requirement decides (managed vs self-managed, lowest operational overhead, cost, global vs regional, latency, data residency, least privilege, Google-recommended practice). Some questions test a precise action (`gcloud` command, IAM role, org policy constraint, firewall rule, load balancer type).
- **Core products**: resource hierarchy, IAM (predefined vs custom roles, service accounts, impersonation, Workload Identity Federation, Workload Identity for GKE), organization policies, VPC (custom mode, Shared VPC, VPC Network Peering, Private Service Connect, Private Google Access, Cloud NAT, Cloud Router, hierarchical firewall policies, Cloud Interconnect Dedicated/Partner, Cross-Cloud Interconnect, HA VPN, Network Connectivity Center), Cloud Load Balancing families (global/regional, external/internal, Application/Network, proxy/passthrough), Cloud CDN, Cloud Armor, Compute Engine (machine families, Spot VMs, MIGs, autoscaling, sole-tenant, custom machine types), GKE (Autopilot vs Standard), Cloud Run, Cloud Run functions, App Engine (legacy), Google Cloud VMware Engine, Cloud Storage (classes, Autoclass, lifecycle, retention/bucket lock, dual/multi-region, turbo replication), Filestore, Persistent Disk/Hyperdisk, Cloud SQL, AlloyDB, Spanner, Bigtable, Firestore, Memorystore, BigQuery, Pub/Sub, Dataflow, Dataproc, Cloud Composer, Datastream, Storage Transfer Service, Transfer Appliance, Database Migration Service, Migration Center, Migrate to Virtual Machines, Backup and DR, Cloud KMS/CMEK/Cloud HSM/EKM, Secret Manager, VPC Service Controls, Access Context Manager, IAP, Chrome Enterprise Premium, Security Command Center, Sensitive Data Protection, Assured Workloads, Cloud Audit Logs, Cloud Monitoring/Logging/Trace/Profiler, SLOs, Cloud Build, Artifact Registry, Cloud Deploy, Binary Authorization, Artifact Analysis, Apigee, API Gateway, Terraform and Infrastructure Manager, Config Connector, emulators, Gemini Cloud Assist, Gemini models, Model Garden, Agent Platform (as the guide names it), AI Hypercomputer, TPUs/GPUs, Model Armor.
- **Classic traps**: Shared VPC vs peering (non-transitive) vs PSC; Cloud NAT is not for inbound; global external Application LB vs regional vs passthrough Network LB (client IP); Spanner vs Cloud SQL vs AlloyDB vs Bigtable vs BigQuery by workload; Standard vs Nearline/Coldline/Archive minimum durations; regional vs multi-region RPO/RTO; Spot VMs (no SLA; preemption notice 0 s by default or 120 s, then up to 30 s best-effort shutdown); basic roles vs predefined; service account keys vs impersonation vs Workload Identity Federation; VPC Service Controls (exfiltration) vs firewall vs IAM; CMEK vs CSEK vs default encryption; Interconnect vs HA VPN SLA (99.99 % needs redundant topology); lift-and-shift vs refactor; Cloud Run vs GKE vs Compute Engine by control and overhead; Cloud Deploy and canary; error budgets and SLOs.
- **Out of scope**: deep data science, product internals not exposed to users, Google Workspace administration.
- **Difficulty**: 20 % easy, 50 % medium, 30 % hard (hard = two valid designs separated by one stated requirement, or multi-step design choices).
- Every product name, launch stage and limit must be checked on cloud.google.com in November 2026: the exam guide uses 2026 names (Gemini Enterprise Agent Platform, Agent Platform Pipelines, Cloud Run functions, Chrome Enterprise Premium).
- **Names and stages checked on 2026-11-27 (use them everywhere)**: docs live at docs.cloud.google.com (cloud.google.com docs URLs redirect there); Vertex AI → Gemini Enterprise Agent Platform (Agent Engine → Agent Runtime, Vertex AI Search → Agent Search, custom training → serverless training); Dataproc → Managed Service for Apache Spark; Cloud Composer → Managed Service for Apache Airflow; Log Analytics → Observability Analytics; Anywhere Cache → Rapid Cache; NotebookLM Enterprise → Gemini Notebook for business; IAM basic roles now Admin/Writer/Reader (Owner/Editor/Viewer legacy). When a renamed product is the answer, write "X (formerly Y)" once in the explanation. Preview or deprecated, never a correct answer: Gemini Cloud Assist as a whole (Preview; except where objective 1.2.6/5.1.5 tests it directly), global external passthrough Network LB, Binary Authorization continuous validation, Policy Controller (deprecated), Deployment Manager (end of support 2026-03-31), Video Intelligence API (deprecated), CSEK for Compute Engine (deprecated), Memorystore for Memcached (deprecated), Security Command Center Enterprise tier (deprecated).
