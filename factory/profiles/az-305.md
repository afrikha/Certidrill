# AZ-305 exam profile

- Expert level (Azure Solutions Architect Expert; prerequisite: Azure Administrator Associate). 100 minutes per the Learn duration table for exams without labs (the exam page states no time), about 40–60 questions, pass at 700/1000, Microsoft Learn accessible during the exam. No lab. Case studies and "does the solution meet the goal" series.
- **A design exam**: every question is "what should you recommend / include in the recommendation?". The candidate picks a service, tier, SKU, redundancy option or topology from requirements. No command syntax, no code, no portal click path, no step ordering.
- **Stems are requirement-driven and rather long**: a short context (subscriptions, tenants, on-premises datacenter, workloads), then 2–5 bulleted requirements such as "minimize cost", "minimize administrative effort", "RPO of 15 minutes", "survive a zone failure". Each requirement eliminates a distractor; the cheapest or simplest option meeting all of them wins.
- **Formats**: single choice (40–50 %), answer-area drop-downs with two or three selections (15–25 %), three Yes/No statements (10–15 %), "select two" (5–10 %), drag and drop matching requirement to service (5–10 %); `ordering` and `hotarea` are rare.
- **Distractors**: same-family services (SQL Database / Managed Instance / SQL on VM; General Purpose / Business Critical / Hyperscale; Service Bus / Event Grid / Event Hubs / Queue Storage; Front Door / Application Gateway / Traffic Manager / Load Balancer; Azure Backup / Site Recovery; LRS / ZRS / GRS / GZRS; Functions / Logic Apps / Container Apps / AKS / Batch).
- **Classic traps**: RPO vs RTO; zone vs region resilience; cheapest tier that still has the required feature; managed identity vs service principal vs Key Vault; Azure Policy vs RBAC vs locks; failover groups vs geo-replication.
- **Out of scope**: implementation detail (cmdlets, Bicep syntax, KQL), AI services, pipeline authoring.
- Difficulty: 30 % easy, 50 % medium, 20 % hard (hard = three or more competing requirements, or a case-study trade-off).
