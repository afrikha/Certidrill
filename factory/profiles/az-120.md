# AZ-120 exam profile

- 100 minutes, about 45–58 questions, pass at 700/1000, proctored. Specialty level: an architect or engineer who knows SAP (HANA, NetWeaver, Business Suite); Microsoft strongly recommends Azure Administrator Associate first. One case study (an SAP landscape to migrate, with sizing, HA/DR and network requirements) and one "does the solution meet the goal" series.
- **Level**: design trade-offs first, configuration second. "You need to recommend…", "What should you include in the design?", "Which storage / VM series / fencing mechanism should you use?". Stems are 3–6 sentences with explicit constraints (SAPS, RPO/RTO, latency, certified-only, cost, OS: SLES / RHEL / Windows).
- **Formats**: single choice (35–45 %), drop-down with two or three selections (design + setting), Yes/No statements, "select two", drag and drop (component → layer, tool → task), a few ordered procedures (cluster setup, automated deployment). Little code: at most an `az` or PowerShell command, a Bicep fragment or a Pacemaker line to complete.
- **Distractors**: same family — Premium SSD / Premium SSD v2 / Ultra Disk / Azure NetApp Files / Azure Files; availability set / zone / proximity placement group; Azure fence agent / SBD; HANA System Replication / Azure Site Recovery / Azure Backup / snapshots; SAP Deployment Automation Framework / Azure Center for SAP solutions / Bicep; Azure Monitor for SAP solutions / VM Insights / Network Watcher.
- **Trap areas (verify each on Learn)**: what is SAP-certified and supported, Write Accelerator scope, disk caching per volume, load balancer settings for clusters, Site Recovery for the application layer vs database-native replication, RISE with SAP responsibilities and connectivity, reservations vs savings plans.
- **Out of scope**: SAP functional and ABAP topics, HANA administration unrelated to Azure, anything absent from the April 17, 2026 study guide.
- Difficulty: 30 % easy, 50 % medium, 20 % hard. SAP-on-Azure guidance moves fast: fetch every VM series, limit, SLA and product name from Learn.
