# AZ-802 exam profile

- 120 minutes (the time Microsoft gives to associate exams that may contain labs), about 45–58 questions, pass at 700/1000, proctored, English only. One case study (forests, sites, Hyper-V hosts, file servers, an Azure subscription) and one "does the solution meet the goal" series.
- **New exam created in 2026** (replaces AZ-800 and AZ-801, retired on September 30, 2026): do not trust memory of the old exams. **Every fact — feature availability per Windows Server version, cmdlet and parameter names, limits, prerequisites, Azure service names — must be fetched from Microsoft Learn.** The study guide carries no "Skills measured as of" date.
- **Level**: hands-on administration of Windows Server on-premises, in Azure VMs and through Azure Arc. "You need to… What should you do first / use / run?". Stems are 2–5 sentences naming servers (DC1, Server1, VM1), domains, sites and the exact symptom or goal.
- **Formats**: single choice (35–45 %), drop-down completion of a PowerShell command or of a two-part decision, Yes/No statements on an exhibit (servers, GPO links, DNS zones), "select two", drag and drop (tool → task, FSMO role → scope), ordered procedures (promote a DC, seize a role, deploy Azure File Sync, restore AD). PowerShell everywhere, plus `repadmin`, `dcdiag`, `ntdsutil`, `netdom`, `w32tm`, `nltest`, `manage-bde`.
- **Distractors**: same family — RODC / writable DC; gMSA / standalone MSA / user account; JEA / CredSSP / Kerberos delegation; DFS Namespaces / DFS Replication / Azure File Sync / Storage Replica; checkpoint types; Storage Spaces / Storage Spaces Direct; fine-grained password policy / Default Domain Policy; DSRM restore / AD Recycle Bin.
- **Out of scope (not in the study guide)**: Microsoft Entra Connect and identity sync, AD FS, AD CS, Windows containers, migration tools, Azure Backup and Azure Site Recovery, IPAM.
- Difficulty: 30 % easy, 50 % medium, 20 % hard (hard = troubleshooting with two interacting causes or an exact order of operations).
