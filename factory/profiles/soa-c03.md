# SOA-C03 exam profile

- **Format** (SOA-C03 guide v1.2, October 29, 2026; checked 2026-11-19): 130 minutes, 65 questions (50 scored + 15 unscored), scaled 100–1,000, pass 720, compensatory. Domains: monitoring 22 %, reliability 22 %, deployment 22 %, security 16 %, networking 18 %. SOA-C03 in use since September 30, 2025. Our mock scores all 65.
- **Name**: CloudOps Engineer – Associate (formerly SysOps Administrator). **No exam labs**: SOA-C02 labs were suspended on March 28, 2023, and the SOA-C03 guide lists only multiple choice and multiple response. No lab tasks.
- **Level**: associate operator: configure, monitor, fix and automate workloads. Out of scope: designing architectures, CI/CD pipelines or hybrid/multi-VPC networks, developing software, defining governance, capacity planning, TCO, billing.
- **Types**: `single` 4 options, 1 correct (78–88 %); `multi` 5 options / 2 correct ("Choose two.") or 6 / 3 ("Choose three."), 12–22 %, all or nothing.
- **Stems**: 2–5 sentences: a company ("AnyCompany", "a media company"), its environment, a symptom or a requirement, a qualifier ("LEAST operational overhead", "MOST cost-effective", "with the least downtime"), then "Which solution will meet these requirements?". Snippets: CLI output, JSON policies, CloudFormation, agent config, event patterns, flow log records.
- **Traps**: CloudWatch metrics vs logs vs alarms vs composite alarms, metric filters, agent for memory/disk, Logs Insights, EventBridge rule patterns and targets; AWS Config rules and automatic remediation; Systems Manager (Run Command, Patch Manager, Automation, Session Manager, Parameter Store, State Manager); Auto Scaling policies and lifecycle hooks; ELB vs Route 53 health checks; RDS Multi-AZ vs read replicas, RDS Proxy, Aurora Serverless v2; AWS Backup; S3 lifecycle and replication; EBS volume types; CloudFormation StackSets, drift, change sets, rollback; AWS RAM; security groups (stateful) vs NACLs (stateless, ephemeral ports), route tables, VPC Flow Logs, Reachability Analyzer; Route 53 routing policies; CloudFront cache keys, TTLs, invalidations; Compute Optimizer, Trusted Advisor.
- **New vs SOA-C02**: Domain 6 (cost and performance) merged into 1.3; added CloudWatch agent for ECS/EKS, CloudFormation **and CDK**, compliance enforcement (conformance packs), CloudWatch network monitoring; S3 static websites removed. v1.1 (June 1, 2026) added Amazon Bedrock, AWS DevOps Agent, AWS Health Dashboard, Kiro, AWS Security Agent, Amazon S3 Files, DR strategies (backup and restore, pilot light, warm standby, active/active).
- **Closures (verified on AWS pages)**: OpsWorks end of life (Stacks May 26, 2024; all OpsWorks disabled): never an answer. Cloud9 closed to new customers. CodeCommit reopened to new customers November 25, 2025. X-Ray SDKs/daemon in maintenance mode since February 25, 2026: instrument with OpenTelemetry (ADOT). Amazon Q Developer sign-ups closed May 15, 2026 (successor Kiro).
