# AZ-400 exam profile

- Expert level. 120 minutes (deduced from Microsoft's exam-duration page, not printed on the exam page), pass at 700/1000, Microsoft Learn can be opened during the exam. Formats are not published; the simulator uses 45–58 questions, one case study, one "does the solution meet the goal" series.
- **Two toolchains, always**: GitHub (Actions, runners, GitHub Apps, Dependabot, GitHub Advanced Security) and Azure DevOps (Pipelines, agents, service connections, variable groups, Azure Artifacts, Boards). Pipelines are 50–55 % of the exam.
- **Stems**: 3–6 sentences, a team and a deciding constraint ("minimize administrative effort", "no stored secret", "no downtime"), then "What should you use / do first?". Many questions show a YAML pipeline or workflow, Git commands or a KQL query with blanks: write real, valid code.
- **Formats**: single choice (30–40 %), drop-down completion of YAML or commands (15–25 %), "select two" (10–15 %), drag and drop and ordering of steps (5–12 % each), Yes/No statements (5–10 %), rare hot area.
- **Traps**: branch policies vs branch protection rules; Microsoft-hosted vs self-hosted agents and runners, parallel jobs; service principal vs system-assigned vs user-assigned managed identity; workload identity federation vs stored secrets; PAT vs GITHUB_TOKEN vs GitHub App; feeds, views and upstream sources; blue-green vs canary vs ring vs slot swap; environment approvals and checks; Stakeholder access vs outside collaborator; revert vs reset vs history rewriting; Git LFS vs Scalar.
- **Out of scope** (not named in the July 27, 2026 guide): TFVC, third-party CI servers, Kubernetes administration, application coding, authoring classic release pipelines (only their migration to YAML).
- Difficulty: 30 % easy, 50 % medium, 20 % hard.
- Guide revised in July 2026 and both toolchains change monthly: fetch every limit, task name, YAML key and product name from Microsoft Learn.
