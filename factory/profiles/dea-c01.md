# DEA-C01 exam profile

- **Format** (guide v1.1, December 12, 2025; checked 2026-11-19): 130 minutes, 65 questions (50 scored + 15 unscored), scaled 100–1,000, pass 720, compensatory. Domains: ingestion 34 %, datastore 26 %, operations 22 %, governance 18 %. DEA-C01 is current (no successor announced). Our mock scores all 65.
- **Level**: associate data engineer: pick the service, setting or fix that makes the pipeline meet the stated cost and performance. Out of scope: ML training and inference, language-specific syntax, drawing business conclusions from data.
- **Types**: `single` 4 options, 1 correct (78–88 %); `multi` 5 options / 2 correct ("Choose two.") or 6 / 3 ("Choose three."), 12–22 %, all or nothing.
- **Stems**: 2–5 sentences: a company ("AnyCompany"), its sources, volumes and pipeline, a requirement, a qualifier ("LEAST operational overhead", "MOST cost-effective", "near real time", "without managing servers"), then "Which solution will meet these requirements?". Each distractor fails one stated requirement.
- **Code**: SQL (Redshift, Athena DDL/DML, COPY/UNLOAD), PySpark / Glue scripts, JSON (IAM, bucket and key policies, Step Functions), AWS CLI. Questions may use `sql`, `python`, `json` fences; course chapters `python`, `json`, `yaml`, `bash`, `text` (SQL in `text`).
- **Traps**: Kinesis Data Streams (shards, replay, enhanced fan-out) vs Amazon Data Firehose (managed delivery, buffering, format conversion) vs MSK vs SQS; Lambda event source mappings; Glue jobs, crawlers, Data Catalog, job bookmarks, DataBrew, Glue Data Quality; EMR vs Glue vs Redshift vs Lambda for transformations; Redshift distribution/sort keys, Spectrum, Serverless, materialized views, federated queries, data sharing, COPY/UNLOAD; Athena partitioning, partition projection, Parquet/ORC, compression; S3 Lifecycle and storage classes; Iceberg / S3 Tables; Lake Formation vs IAM vs bucket policies, LF-tags; Step Functions vs MWAA vs EventBridge vs Glue workflows; DynamoDB keys, streams, TTL; DMS CDC; HNSW vs IVF; KMS cross-account; Macie for PII.
- **Names and closures (verified on AWS pages, November 2026)**: guide "Amazon Kinesis Data Firehose" is now **Amazon Data Firehose**; Kinesis Data Analytics for SQL shut down January 27, 2026 (use Managed Service for Apache Flink). Maintenance, no new customers: Kendra, Q Business, Glue Ray jobs, S3 Select, S3 Glacier Select, Glacier vaults, Application Discovery Service, Timestream for LiveAnalytics; Data Pipeline closed. Shut down: Snowball Edge, Snowmobile, Lake Formation Governed Tables. Q Developer sign-ups closed May 15, 2026 (Kiro). Data Wrangler now in SageMaker Canvas. AWS SCT left the in-scope list (prefer DMS Schema Conversion). Never make a closed service the correct answer.
