# DP-750 exam profile

- **Exam created in 2026** (Azure Databricks Data Engineer Associate, skills measured as of March 11, 2026). Fetch every fact from Microsoft Learn (Azure Databricks documentation) before writing: product names (Lakeflow Jobs, Lakeflow Connect, Lakeflow Spark Declarative Pipelines, Databricks Asset Bundles, AI/BI Genie), syntax, defaults, limits.
- 120 minutes, pass at 700/1000, 45–58 questions in the simulator (Microsoft publishes no count); Learn announces no lab. The simulator adds one case study (4–6 questions) and one Yes/No series of 3.
- **Level**: associate, hands-on. The candidate reads and completes SQL and Python (PySpark) code, picks a compute type or an ingestion method for stated constraints, and orders the steps of a pipeline or a deployment.
- **Stems**: 3–6 sentences, a catalog.schema.table context, explicit constraints (cost, latency, isolation, least privilege), then "What should you use?", "Which statement should you run?" or "How should you complete the code?".
- **Formats**: single choice (35–45 %), drop-down code completion in SQL, Python or bundle YAML (15–25 %), multiple choice (10–15 %), Yes/No statements (5–10 %), drag and drop, ordering; hot area is rare.
- **Distractors and traps**: job vs serverless vs classic compute vs SQL warehouse; managed vs external table vs volume; COPY INTO vs Auto Loader vs Lakeflow Connect; partitioning vs Z-ordering vs liquid clustering; row filter vs column mask vs ABAC policy; OPTIMIZE vs VACUUM; repair vs restart of a job run; service principal vs managed identity.
- **Out of scope**: anything the study guide does not name (Microsoft Fabric, Azure Synapse, model training and serving). Azure Data Factory, Microsoft Entra and Azure Monitor only at the level of the objectives that cite them.
- Difficulty: 30 % easy, 50 % medium, 20 % hard (hard = two constraints combined).
