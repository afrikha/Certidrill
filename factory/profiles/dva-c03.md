# DVA-C03 exam profile

- **Format** (DVA-C03 guide, no version printed; checked 2026-11-19): 130 minutes, 65 questions (50 scored + 15 unscored), scaled 100–1,000, pass 720, compensatory. Domains: development 30 %, security 26 %, deployment 22 %, troubleshooting 22 %. DVA-C02 ends November 30, 2026; DVA-C03 from December 1, 2026. Our mock scores all 65.
- **Level**: associate developer: pick the API call, SDK setting, configuration or deployment option that makes the code work. Out of scope: designing architectures or CI/CD pipelines, administering IAM users, choosing foundation models, prompt engineering, RAG, designing guardrails.
- **Types**: `single` 4 options, 1 correct (78–88 %); `multi` 5 options / 2 correct ("Choose two.") or 6 / 3 ("Choose three."), 12–22 %, all or nothing.
- **Stems**: 2–5 sentences: a company ("AnyCompany"), its application, a requirement, a qualifier ("LEAST operational overhead", "LEAST development effort", "MOST cost-effective", "MOST secure", "without changing the application code"), then "Which solution will meet these requirements?". Each distractor fails one stated requirement.
- **Code**: Python (boto3) or JavaScript (SDK v3) snippets, JSON policies, YAML (CloudFormation, SAM, buildspec, appspec), AWS CLI, Logs Insights queries. Questions may use `python`/`javascript` fences; course chapters only `bash`, `json`, `yaml`, `text` (Python/JavaScript in `text`).
- **Traps**: DynamoDB keys and cardinality, GSI vs LSI, RCU/WCU arithmetic, Query vs Scan, conditional writes; Lambda reserved vs provisioned concurrency, timeouts, layers, environment variables, destinations vs DLQ, event source mappings; SQS visibility timeout, DLQ, FIFO; API Gateway stages, throttling, caching, Lambda proxy; Cognito user pools vs identity pools; KMS envelope encryption, Secrets Manager vs Parameter Store; X-Ray, CloudWatch Logs/metrics; buildspec, appspec, CodeDeploy deployment types, CodePipeline; SAM/CDK/CloudFormation; Elastic Beanstalk deployment policies; caching strategies; Step Functions.
- **New vs DVA-C02**: task 2.3 (AI integration security: access, private connectivity, no training on data, content filtering, PII redaction, prompt injection, agent tool authorization, human-in-the-loop, logs); AI-assisted coding (1.1.9), managed AI services (1.1.10), AI tools in tests, CI/CD, troubleshooting, optimization (3.2.5, 3.3.9, 4.1.5, 4.3.6); presigned URLs; container images and ECS/EKS/Fargate deployment. AI services in scope: Bedrock, Bedrock AgentCore, Amazon Quick, Kiro.
- **Closures (verified on AWS pages)**: Amazon Q Developer sign-ups closed May 15, 2026 (IDE plugins end April 30, 2027; successor Kiro; not in scope). Cloud9 closed to new customers (July 25, 2024). CodeCommit reopened to new customers November 25, 2025. X-Ray SDKs/daemon in maintenance since February 25, 2026, end of support February 25, 2027: use OpenTelemetry (ADOT); X-Ray continues. AWS Copilot CLI (skill 3.2.4) end of support June 12, 2026: never the recommended choice. Glacier vaults closed to new customers (per A-aws-1).
- **In-scope services (guide, non-exhaustive)**: Analytics: Athena, Data Firehose, Kinesis, OpenSearch Service. Application Integration: EventBridge, SNS, SQS, Step Functions. Compute: EC2, Elastic Beanstalk, Lambda. Containers: ECR, ECS, EKS. Database: Aurora, DynamoDB, ElastiCache, RDS. Developer Tools: Amplify, CloudShell, CodeArtifact, CodeBuild, CodeDeploy, CodePipeline, X-Ray. Machine Learning and AI: Bedrock, Bedrock AgentCore, Amazon Quick, Kiro. Management and Governance: AppConfig, CDK, CloudFormation, CloudTrail, CloudWatch, CloudWatch Logs, AWS CLI, AWS SAM, Systems Manager. Networking and Content Delivery: API Gateway, CloudFront, ELB, PrivateLink, Route 53, VPC. Security: ACM, Cognito, IAM, KMS, Private CA, Secrets Manager, STS, WAF. Storage: EBS, EFS, S3, S3 Glacier.
- **Out-of-scope services (guide)**: Amazon Quick Sight; Connect, WorkMail; AppStream 2.0, WorkSpaces; GameLift; Polly, Rekognition, SageMaker AI, Strands Agents; AWS Managed Services (AMS); Elastic Transcoder; Application Discovery Service, Application Migration Service, Transfer Family; Shield Advanced, Shield Standard; Snow Family, Storage Gateway.

- Difficulty: 30 % easy, 50 % medium, 20 % hard (hard: only the qualifier separates two working fixes).
