# DP-900 exam profile

- 45 minutes, about 35–45 questions, pass at 700/1000, closed book. No case study, no lab, no "does the solution meet the goal" series.
- **Level**: recognize a data concept or choose the right Azure data service for a need. The only "code" is elementary SQL: recognize what a statement does and its family (query, data manipulation, data definition, data control). No CLI, no portal procedure, no DAX or Spark code.
- **Stems are short**: one to three sentences. "Which type of data is ...?", "Which Azure service should you use to ...?", three Yes/No statements, "Select the answer that correctly completes the sentence.", "Match each data role to its task.".
- **Formats**: single (40–55 %), Yes/No statements (20–30 %), dropdown (10–15 %), multi "select two" (5–10 %), dragdrop (5–10 %); `ordering` and `hotarea` rare.
- **Distractors**: same family (Azure SQL Database / SQL Managed Instance / SQL Server on Azure Virtual Machines / open-source database services; Blob storage / Azure Files / Table storage / Azure Cosmos DB APIs; Azure Databricks / Microsoft Fabric; Power BI components).
- **Classic traps**: structured vs semi-structured vs unstructured; transactional vs analytical; administrator vs engineer vs analyst; normalization, views, stored procedures, indexes; PaaS vs IaaS in the Azure SQL family; which Cosmos DB API for which data model; batch vs streaming; data lake vs data warehouse vs lakehouse; fact and dimension tables; which visual for which data.
- **Scope check (July 21, 2026)**: for large-scale and real-time analytics the study guide names only Azure Databricks and Microsoft Fabric. Before writing about another analytics service, verify on Microsoft Learn that the current DP-900 learning paths still teach it; otherwise no question.
- Difficulty: 40 % easy, 45 % medium, 15 % hard (two concepts combined or a subtle Yes/No statement).
