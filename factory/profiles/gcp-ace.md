# Google Cloud Associate Cloud Engineer — exam profile

- **Format** (cloud.google.com/learn/certification/cloud-engineer, checked 2026-11-27): 2 hours, 50–60 multiple choice and multiple select questions, English, Japanese, Spanish and Portuguese (Certidrill: **English only**), no case study. Pass/fail only. Recommended: 6+ months of hands-on Google Cloud experience. Exam guide: services.google.com/fh/files/misc/associate_cloud_engineer_exam_guide_english.pdf (4 sections ~20 / 30 / 30 / 20 %).
- **Level**: associate, hands-on. Compared with Professional Cloud Architect, fewer architecture trade-offs and more "how do you do it": the right `gcloud` / `gsutil`-`gcloud storage` / `bq` / `kubectl` command and flag, the console step, the predefined IAM role, the right product for a simple stated need, the cheapest or least-effort option. Many stems end with "What should you do?" and the options are concrete actions or commands. A command option must be syntactically real: check every command group and flag on the gcloud reference (docs.cloud.google.com/sdk/gcloud/reference/...).
- **Core topics**: projects, folders, organization, org policy constraints, Cloud Identity users/groups and Google Cloud Directory Sync, enabling APIs (`gcloud services enable`), quotas, regions/zones; billing accounts, Billing Account User/Administrator roles, budgets and alerts, export to BigQuery; Compute Engine (machine families, custom machine types, Spot VMs, availability policy, SSH keys, OS Login, VM Manager, instance templates, MIGs and autoscaling, disks: zonal/regional Persistent Disk, Hyperdisk, snapshots and schedules, images); GKE (Autopilot vs Standard, regional and private clusters, node pools and autoscaling, `kubectl` and `gcloud container clusters get-credentials`, Deployments, Services, StatefulSets, HPA/VPA, Artifact Registry access); Cloud Run (revisions, traffic splitting, autoscaling, min/max instances), Cloud Run functions, Eventarc, Pub/Sub triggers; storage and data products (Cloud Storage classes and lifecycle, Filestore, NetApp Volumes, Managed Lustre, Cloud SQL, AlloyDB, Spanner, Bigtable, Firestore, BigQuery, Memorystore, Managed Service for Apache Kafka, Dataflow, Storage Transfer Service), backups and restores, Database Center, CMEK; VPC (custom mode, subnets and expansion, Shared VPC, peering), firewall rules and Cloud NGFW policies, secure Tags, Cloud VPN, Interconnect, load balancers, Network Service Tiers, static IPs, routes, Cloud DNS, Cloud NAT; Cloud Logging (log buckets, sinks, Log Router, Observability Analytics, audit logs, VPC Flow Logs, firewall logs), Cloud Monitoring (alerts, custom and log-based metrics), Ops Agent, Managed Service for Prometheus, Cloud Trace/Profiler, Query Insights, Personalized Service Health, Active Assist, Cloud Hub; IAM (basic/predefined/custom roles, inheritance, policies, conditions), service accounts (Google-managed, attaching, impersonation, short-lived credentials, Workload Identity Federation for GKE, Workload Identity Federation), Workforce Identity Federation; IaC (Terraform, Config Connector, Helm, Fabric FAST), AI-assisted tools named in the guide; Agent Runtime and Workbench (Gemini Enterprise Agent Platform), Cloud Workstations, GPUs/TPUs.
- **Classic traps**: `gcloud config set project` vs `--project`; enabling an API before use; Billing Account User needed to link a project; budgets alert but do not stop spending (unless spend cap budgets apply — check); Nearline/Coldline/Archive minimum storage durations and retrieval fees; lifecycle `SetStorageClass` rules; Spot VMs can be preempted (notice 0 s or 120 s, then up to 30 s shutdown); MIG autoscaling needs an instance template; subnet ranges can be expanded but not shrunk; firewall rules are stateful, implied deny ingress / allow egress, priority lower number wins; Cloud NAT only for outbound; external IP release; Cloud Run traffic to a tagged revision; HPA vs VPA vs cluster autoscaler; Autopilot billing per Pod requests; IAM roles granted at a higher level are inherited and cannot be revoked lower down (except deny policies); service account keys are a last resort; log sinks need a writer identity with access to the destination; `_Required` vs `_Default` buckets and retention; Data Access audit logs off by default.
- **Difficulty**: 30 % easy, 50 % medium, 20 % hard (hard = several plausible commands or settings, one detail decides).
- **Names and stages checked on 2026-11-27 (use them everywhere)**: docs at docs.cloud.google.com; Vertex AI → Gemini Enterprise Agent Platform (Agent Engine → Agent Runtime, Vertex AI Workbench → Agent Platform Workbench, `roles/aiplatform.user` titled "Agent Platform User"); Dataproc → Managed Service for Apache Spark; Cloud Composer → Managed Service for Apache Airflow; Log Analytics → Observability Analytics (the exam guide still writes "log analytics"); IAM basic roles Admin/Writer/Reader (Owner/Editor/Viewer legacy); Cloud Functions → Cloud Run functions; Container Registry shut down (Artifact Registry). Preview or deprecated, never a correct answer unless the objective names the product (then state the launch stage in the explanation): Gemini Cloud Assist (Preview), Gemini CLI and Google Antigravity (check stage), Deployment Manager (end of support 2026-03-31), Policy Controller (deprecated), CSEK for Compute Engine (deprecated), Memorystore for Memcached (deprecated). Application Design Center is GA since 2025-12-05.
