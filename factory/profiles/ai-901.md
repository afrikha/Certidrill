# AI-901 exam profile

- 45 minutes, about 35–45 questions, pass at 700/1000, closed book. No case study, no lab, no "does the solution meet the goal" series.
- **Exam created in 2026 (skills measured as of April 15, 2026; replaces AI-900). What you remember of AI-900 is wrong here: fetch every fact, product name, portal step, SDK name and parameter from Microsoft Learn** (learning path "Get started with AI applications and agents on Azure"). Use the study guide's names: Microsoft Foundry, Foundry portal, Foundry SDK, Foundry Tools, Azure Speech in Foundry Tools, Azure Content Understanding in Foundry Tools.
- **Level**: 40–45 % concepts (responsible AI, how generative models work, choosing a model, deployment options and parameters, recognizing a workload); 55–60 % "implement with Foundry": which portal action, which tool or model, what a short Python snippet does. Read and complete simple code; never design an architecture.
- **Stems are short**: "Which responsible AI principle ...?", "You need to ... What should you use?", three Yes/No statements, sentence or code completion, matching workloads to scenarios.
- **Formats**: single (40–55 %), Yes/No statements (20–30 %), dropdown including short code completion (10–15 %), multi (5–10 %), dragdrop (5–10 %); ordering (portal steps) and hotarea rare.
- **Classic traps**: fairness vs inclusiveness; transparency vs accountability; reliability and safety vs privacy and security; system vs user prompt; model parameters; speech recognition vs synthesis; multimodal model vs dedicated Foundry Tool; image analysis vs image generation; Content Understanding per content type; chat client vs agent client.
- **Out of scope — no question**: machine learning theory and Azure Machine Learning (regression, classification, clustering), training or fine-tuning, multi-agent orchestration, Foundry IQ, voice agents.
- Difficulty: 40 % easy, 45 % medium, 15 % hard (two concepts combined or a code/portal detail verified on Learn, never trivia).
