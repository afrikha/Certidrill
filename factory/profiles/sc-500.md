
# SC-500 exam profile

- **Exam**: Implementing End-to-End Security Controls for Cloud and AI Workloads. 120 minutes, pass at 700/1000, proctored, available in French, "may have interactive components"; Microsoft publishes neither the number of questions (about 40–60) nor the formats. Microsoft Learn is accessible during role-based exams.
- **Created in 2026: fetch every fact from Microsoft Learn**: Defender for Cloud plan names and contents, role names, portal paths, limits, licences. Critical for the AI objectives (Microsoft Entra Agent ID, Purview DSPM, AI Gateway, Foundry guardrails, Security Copilot agents). Nothing from memory.
- **Level**: associate, implementation. Mostly portal settings, role and policy choices, order of operations; some Azure CLI / PowerShell, Azure Policy JSON, Bicep and KQL to read.
- **Stems**: 3–6 sentences, often with an exhibit (table of VMs, subnets, NSG rules, users and roles), one or two constraints (least privilege, minimize administrative effort, no public access), then "What should you do?".
- **Formats (bank target)**: single choice (35–45 %), "select two" (10–15 %), Yes/No statements (10–15 %), drop-down completion (10–15 %), drag and drop (5–10 %), ordering (5–10 %), one case study, one "does the solution meet the goal" series.
- **Classic traps**: PIM eligible vs active; Key Vault RBAC vs access policies, soft delete vs purge protection; Azure roles vs Microsoft Entra roles; Policy effects (`Deny`, `Audit`, `DeployIfNotExists`, `Modify`); service endpoint vs private endpoint vs Private Link service; NSG vs security admin rules vs Azure Firewall; SAS types; Azure Disk Encryption vs encryption at host; Defender CSPM vs foundational CSPM; Defender for Servers plans; Sentinel automation rule vs playbook.
- **Out of scope**: incident investigation and threat hunting, identity lifecycle governance, Purview DLP and labeling policies, architecture design.
- Difficulty: 30 % easy, 50 % medium, 20 % hard (hard = several controls interacting, or a subtle exhibit).
