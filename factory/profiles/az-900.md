# AZ-900 exam profile

- 45 minutes, about 35–45 questions, pass at 700/1000, closed book. No case study, no lab, no "does the solution meet the goal" series.
- **Level**: recognize a concept or choose the right service for a need. No command syntax, no configuration parameter, no address calculation, no code. Never go deeper than the AZ-900 course chapters in `content/az-900/course/chapters/`.
- **Stems are short**: one to three sentences. Typical forms: "Your company plans to migrate ... Which cloud benefit ...?", "Which Azure service should you use to ...?", "For each of the following statements, select Yes if the statement is true. Otherwise, select No.", "Select the answer that correctly completes the sentence." (dropdown with `layout: text`), "Match each service to its description." (dragdrop).
- **Formats**: single choice (40–55 %), three Yes/No statements (20–30 %), sentence completion with drop-down (10–15 %), multiple choice "select two" (5–10 %), matching by drag and drop (5–10 %); `ordering` and `hotarea` are rare; no `series_yesno`.
- **Distractors**: real Azure services of the same family (Advisor / Monitor / Service Health / Resource Health; Policy / RBAC / locks / Purview; VPN Gateway / ExpressRoute / peering; AzCopy / Storage Explorer / File Sync / Data Box / Azure Migrate; Entra ID / Entra Domain Services).
- **Classic traps to cover**: shared responsibility per IaaS/PaaS/SaaS; CapEx vs OpEx; vertical vs horizontal scaling; availability zone vs region pair vs availability set; resource groups cannot be nested, one resource = one group; lock vs RBAC vs Policy; pricing calculator vs Cost Management; Service Health vs Resource Health vs Monitor; tags are not inherited; hot/cool/cold/archive; LRS/ZRS/GRS/GZRS.
- **Not in the current study guide (July 20, 2026) — write no question on them**: TCO calculator, Service Trust Portal, composite SLA calculation, service lifecycle (preview/GA).
- Difficulty: 40 % easy, 45 % medium, 15 % hard (hard = two concepts combined or a subtle Yes/No statement, never obscure trivia).
