# SCS-C03 exam profile

- **Format** (guide v1.0, March 26, 2026; checked 2026-11-19): 170 minutes, 65 questions (50 scored + 15 unscored), scaled 100–1,000, pass **750**, compensatory. Domains: detection 16 %, incident 14 %, infrastructure 18 %, identity 20 %, data 18 %, governance 14 %. SCS-C03 since December 2, 2025 (SCS-C02 until December 1). Mock: all 65 scored.
- **Level**: specialty, 3–5 years securing cloud. Out of scope: crypto algorithm design, packet analysis, whole-deployment architecture, ML training.
- **Types**: `single` 4 options (about 79 %); `multi` 5 options / 2 correct ("Choose two.") or 6 / 3 ("Choose three."), about 15 %, all or nothing; a few **ordering** (3–5 steps to put in order, e.g. an incident-response or key-rotation sequence) and **matching** (`dragdrop`, 3–7 prompts matched to services or controls) items, about 3 % each, all or nothing. YAML format for these: see `content/aif-c01/questions/` (types `ordering`, `dragdrop`).
- **Stems**: 3–8 sentences: a company ("AnyCompany"), its accounts and setup, precise security requirements (least privilege, encryption scope, cross-account access, automated response, audit evidence), a qualifier ("LEAST operational overhead", "MOST cost-effective", "MOST secure"), then "Which solution will meet these requirements?". Options are concrete configurations or policies. Hard = one condition key, policy type or the qualifier decides.
- **Traps**: policy evaluation (explicit deny; SCPs/RCPs cap, never grant; boundaries and session policies intersect; cross-account needs both sides); KMS key policies vs grants, multi-Region keys, imported material (on-demand rotation only, expiration), external vs CloudHSM key stores (manual rotation); S3 Block Public Access, Object Lock modes, `aws:SourceVpce` / `aws:PrincipalOrgID`; GuardDuty vs Inspector vs Macie vs Security Hub vs Detective; organization trails, Config rules, conformance packs, EventBridge + Lambda / SSM Automation remediation; EC2 isolation, EBS snapshots, forensics account; WAF vs Shield Advanced vs Network Firewall vs Firewall Manager, security groups vs NACLs; Secrets Manager vs Parameter Store; ACM vs Private CA; Identity Center vs Cognito vs Roles Anywhere; Verified Access; Security Lake (OCSF).
- **New vs SCS-C02**: domains 1–2 rebuilt, domain 6 renamed. Added: finding validation, OCSF and third-party WAF rules, GenAI guardrails (OWASP Top 10 for LLM), inter-node encryption, imported vs AWS-generated key material, data masking, multi-Region keys and certificates. Removed: ASFF, host firewalls, TCP/IP basics, Reachability Analyzer, TLS concepts, VIFs, S3 static websites.
