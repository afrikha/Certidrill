# CLF-C02 exam profile

- **Format** (exam guide v1.3, October 29, 2026; certification page checked 2026-11-19): 90 minutes, 65 questions (50 scored + 15 unscored, not identified), scaled score 100–1,000, pass at 700, compensatory scoring (no per-domain pass). Domains: concepts 24 %, security 30 %, technology 34 %, billing 12 %. The mock exam scores all 65.
- **Level**: foundational, up to 6 months of exposure to AWS, independent of a job role. The candidate recognises a concept, a service, a pillar, a purchasing option or a support plan; no coding, CLI syntax, console path or architecture design.
- **Types**: `single`: 4 options, 1 correct (85–92 %); `multi`: 5 options with 2 correct ("Choose two."), rarely 6 with 3 ("Choose three."), 8–15 %. No case study, no Yes/No series, no drop-down, no drag and drop.
- **Stems**: short, 1–3 sentences, one fact or one service to identify. "A company wants to ... Which AWS service will meet this requirement?", "Which pillar of the AWS Well-Architected Framework ...?", "Which task is the customer's responsibility under the AWS shared responsibility model?", "Which is the MOST cost-effective Support plan that includes ...?". Neutral company names ("A retail company", "AnyCompany"). Options are service or concept names or one short sentence; distractors come from the same family.
- **Classic traps**: shared responsibility shifting by service type (EC2 guest OS and patching = customer; RDS and Lambda = AWS manages OS; data, IAM and encryption choices always customer); Savings Plans (Compute vs EC2 Instance) vs Reserved Instances (Standard vs Convertible, regional vs zonal) vs Spot vs Dedicated Hosts (BYOL per-socket) vs Capacity Reservations; Support plan features and response times (Basic, Business Support+, Enterprise Support, Unified Operations: check the current plan page); Well-Architected pillars vs AWS CAF perspectives; Regions vs Availability Zones vs edge locations; AWS Artifact (compliance reports) vs AWS Config (resource configuration history) vs CloudTrail (API calls) vs CloudWatch (metrics, logs); Trusted Advisor (best-practice checks) vs Compute Optimizer (rightsizing from utilisation); Cost Explorer (past and forecast) vs Budgets (alerts) vs Pricing Calculator (estimate before deploying) vs Cost and Usage Report; Shield vs WAF vs GuardDuty vs Inspector vs Macie; security groups (stateful) vs network ACLs (stateless); EBS vs instance store vs EFS; root-user-only tasks.
- **In-scope services (guide, non-exhaustive)**: Analytics: Athena, EMR, Glue, Kinesis, OpenSearch Service, Amazon Quick, Redshift. Application Integration: EventBridge, SNS, SQS, Step Functions. Business Applications: Connect, SES. Cloud Financial Management: Budgets, Cost and Usage Reports, Cost Explorer, AWS Marketplace. Compute: Batch, EC2, Elastic Beanstalk, Lightsail, Outposts. Containers: ECR, ECS, EKS. Customer Enablement: AWS Support. Database: Aurora, DocumentDB, DynamoDB, ElastiCache, Neptune, RDS. Developer Tools: AWS CLI, CodeBuild, CodePipeline, X-Ray. End User Computing: AppStream 2.0, WorkSpaces, WorkSpaces Secure Browser. Frontend Web and Mobile: Amplify. IoT: IoT Core. Machine Learning: Comprehend, Lex, Polly, Amazon Q, Rekognition, SageMaker AI, Textract, Transcribe, Translate. Management and Governance: AWS Auto Scaling, CloudFormation, CloudTrail, CloudWatch, Compute Optimizer, Config, Control Tower, Health Dashboard, License Manager, Management Console, Organizations, Service Catalog, Service Quotas, Systems Manager, Trusted Advisor, Well-Architected Tool. Migration and Transfer: Application Discovery Service, Application Migration Service, DMS, Migration Evaluator, Migration Hub, SCT. Networking and Content Delivery: API Gateway, CloudFront, Direct Connect, Global Accelerator, PrivateLink, Route 53, Transit Gateway, VPC, AWS VPN, Site-to-Site VPN, Client VPN. Security, Identity, and Compliance: Artifact, ACM, CloudHSM, Cognito, Detective, Directory Service, Firewall Manager, GuardDuty, IAM, IAM Identity Center, Inspector, KMS, Macie, RAM, Secrets Manager, Security Hub, Shield, WAF. Serverless: Fargate, Lambda. Storage: AWS Backup, EBS, EFS, Elastic Disaster Recovery, FSx, S3, S3 Glacier, Storage Gateway.
- **Out-of-scope services (guide)**: AppFlow; Clean Rooms; Data Exchange; DataZone; MSK; AppFabric; Simple Workflow Service; Copilot; Wavelength; Application Cost Profiler; DevPay; Activate; IQ; Managed Services (AMS); Billing Conductor; Keyspaces; MemoryDB; AppConfig; Application Composer; CodeArtifact; CodeDeploy; CodeGuru; CloudShell; Device Farm; GameLift; IoT Device Defender; IoT Greengrass; Fraud Detector; Personalize; Chatbot; Data Lifecycle Manager; Launch Wizard; AWS Elemental (Appliances and Software, MediaConnect, MediaConvert, MediaLive, MediaPackage, MediaTailor); IVS; Migration Hub Refactor Spaces; Transfer Family; Cloud Map; Network Access Analyzer; Ground Station; VPC Lattice; Cloud Directory; Network Firewall; FSx for Lustre (FSx itself is in scope).
- **Verify availability (November 2026)** before making a service the correct answer: AWS Migration Hub (no new customers since November 7, 2025) and AWS Application Discovery Service (no new customers; AWS Transform suggested) are closed to new customers, like Amazon Glacier vaults (S3 Glacier storage classes are not affected); Amazon AppStream 2.0 is now documented as Amazon WorkSpaces Applications; the Support plans are now Basic, Business Support+, Enterprise Support and Unified Operations. Never make a closed service or a retired plan the right answer.
- Difficulty: 40 % easy, 45 % medium, 15 % hard (hard = two same-family services separated by one stated detail).
