# DP-600 exam profile

- 100 minutes, pass at 700/1000, associate, no lab. Microsoft Learn is reachable during the exam: test judgement, not lookups. Number of questions (40–60 in general) and formats per exam are not published; our blueprint assumes one case study (4–6 questions) and one Yes/No series of 3.
- **Scope**: study guide "as of October 19, 2026": security and lifecycle (25–30 %), prepare data (45–50 %), semantic models (25–30 %). Fabric changes monthly: fetch every limit, setting name and behaviour from Learn.
- **Stems**: 3–6 sentences with named items ("You have a Fabric workspace named Workspace1 that contains a lakehouse named Lakehouse1..."), one or two requirements (minimize effort, least privilege, refresh time), then "What should you do?", "Which storage mode should you use?", "How should you complete the code?".
- **Formats**: single (35–45 %), drop-down code completion in T-SQL, KQL or DAX, sometimes PySpark (15–25 %), multi (10–15 %), Yes/No statements, drag and drop, ordered steps, rare hot area.
- **Hands-on level**: read and complete short queries and measures; choose a setting, permission or tool; design trade-offs (lakehouse, warehouse or eventhouse; shortcut, copy or mirroring; Import, DirectQuery or Direct Lake).
- **Classic traps**: workspace roles vs item permissions; where RLS, CLS, OLS and file-level security are defined and enforced; Direct Lake fallback and refresh; Direct Lake on OneLake vs on SQL analytics endpoint; Git integration vs deployment pipelines; .pbip vs .pbit vs .pbids; XMLA read vs read/write; calculation groups vs field parameters; iterators vs simple aggregations.
- **Out of scope**: capacity and tenant administration, gateways, report design (PL-300), Spark tuning, orchestration and streaming engineering (DP-700), data science.
- Difficulty: 30 % easy, 50 % medium, 20 % hard (two constraints combined or subtle code, never trivia).
