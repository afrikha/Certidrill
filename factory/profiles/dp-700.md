# DP-700 exam profile

- 100 minutes, pass at 700/1000, associate, no lab. Microsoft Learn is reachable during the exam: test judgement, not lookups. Number of questions (40–60 in general) and formats per exam are not published; our blueprint assumes one case study (4–6 questions) and one Yes/No series of 3.
- **Scope**: study guide "as of October 19, 2026", three areas of 30–35 % each: implement and manage (workspace settings, lifecycle, security, orchestration), ingest and transform (batch, streaming), monitor and optimize. Fabric changes monthly: fetch every limit, setting name, command and behaviour from Learn.
- **Stems**: 3–6 sentences with named items ("You have a Fabric workspace named Workspace1 that contains a lakehouse named Lakehouse1 and a warehouse named DW1..."), requirements (minimize development effort, cost or latency), then "What should you use?", "What should you do first?", "How should you complete the code?".
- **Formats**: single (35–45 %), drop-down code completion in PySpark, T-SQL or KQL (15–25 %), multi (10–15 %), Yes/No statements, drag and drop, ordered steps, rare hot area.
- **Hands-on level**: high. Read and complete Spark, T-SQL and KQL code and pipeline expressions; pick the setting or monitoring tool; troubleshoot from an error description; choose between engines.
- **Classic traps**: lakehouse vs warehouse vs eventhouse; Dataflow Gen2 vs pipeline vs notebook; shortcut vs mirroring vs copy; full vs incremental load, late-arriving data; eventstream vs Spark structured streaming vs KQL; window types; workspace roles vs item permissions vs OneLake security; RLS, CLS, dynamic data masking; Git integration vs deployment pipelines vs database projects; Delta table maintenance.
- **Out of scope**: semantic model design and DAX (DP-600; only refresh monitoring here), report design, data science, Azure Data Factory, Synapse and Databricks outside Fabric.
- Difficulty: 30 % easy, 50 % medium, 20 % hard (two constraints combined or subtle code, never trivia).
