
# AI-300 exam profile

- **Exam**: Operationalizing Machine Learning and Generative AI Solutions (Machine Learning Operations Engineer Associate). 120 minutes, pass at 700/1000, proctored, English only, "may have interactive components"; Microsoft publishes neither the number of questions (about 40–60) nor the formats. Microsoft Learn is accessible during role-based exams.
- **Created in 2026: fetch every fact from Microsoft Learn** (Azure Machine Learning and Microsoft Foundry docs): product and portal names, CLI v2 / Python SDK v2 syntax, YAML keys, role names, evaluator names, deployment types. Nothing from memory.
- **Level**: associate, hands-on. Expect `az ml` commands, job/component/pipeline/endpoint YAML, MLflow Python calls, Bicep resources and GitHub Actions workflows to complete or read.
- **Stems**: 3–6 sentences: an existing workspace or Foundry project, one or two constraints (least privilege, no public network access, lowest cost, no downtime), then "What should you do?".
- **Formats (bank target)**: single choice (35–45 %), code or YAML completion with drop-downs (15–20 %), "select two" (10–15 %), Yes/No statements (5–10 %), drag and drop (5–10 %), ordering (5–10 %), one case study, one "does the solution meet the goal" series.
- **Classic traps**: datastore vs data asset (`uri_file` / `uri_folder` / `mltable`); compute instance vs cluster vs serverless; workspace vs registry scope; managed online vs batch endpoint; blue-green traffic split vs mirrored traffic; data drift vs prediction drift vs data quality; serverless API vs managed compute vs provisioned throughput; groundedness vs relevance; fine-tuning vs RAG vs prompt engineering.
- **Out of scope**: algorithm theory, Azure Databricks and Fabric, CLI v1 / SDK v1, agent development, Azure DevOps pipelines.
- Difficulty: 30 % easy, 50 % medium, 20 % hard (hard = two constraints combined, or a subtle error in code).
