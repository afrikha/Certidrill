# DP-300 exam profile

- 100 minutes, pass at 700/1000, proctored, associate level. Question count not published (bank target: 45–58, one case study of 4–6 questions, one "does the solution meet the goal" series of 3). No lab announced.
- **Scope**: Azure SQL Database, Azure SQL Managed Instance, SQL Server on Azure Virtual Machines (Windows and Linux), SQL Server on-premises and Azure Arc-enabled SQL Server, SQL database in Microsoft Fabric (use cases only). Skills measured as of October 27, 2026: recheck on Learn every recent topic (database watcher, Fabric, Arc, secure enclaves, ledger).
- **Stems**: operational scenarios of 3–6 sentences ("You have an Azure SQL managed instance named MI1 that ... You need to ... The solution must minimize administrative effort / cost / downtime."). The stated constraint (RPO/RTO, online vs offline, least privilege, cost) decides the answer.
- **Hands-on level**: high. T-SQL to complete (`CREATE USER ... FROM EXTERNAL PROVIDER`, `ALTER DATABASE`, `BACKUP ... TO URL`, `DBCC`, DMVs, Query Store views), Azure CLI / Azure PowerShell / Bicep fragments, portal steps in order. `dropdown` for code completion, `ordering` for procedures, `dragdrop` for feature-to-requirement matching.
- **Typical traps**: which feature exists on which offering (SQL Server Agent vs elastic jobs; failover groups vs active geo-replication vs availability groups); DTU vs vCore, General Purpose / Business Critical / Hyperscale, serverless; server-level vs database-level firewall rules and principals; dynamic data masking vs Always Encrypted vs row-level security vs TDE; PITR vs LTR vs geo-restore; online vs offline migration tools.
- **Out of scope**: application development, Azure Database for PostgreSQL/MySQL, Azure Cosmos DB, Fabric data engineering.
- **Difficulty**: 30 % easy, 50 % medium, 20 % hard (hard = several constraints or two features combined, never obscure trivia).
