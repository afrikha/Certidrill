# DOP-C02 exam profile

- **Format** (DOP-C02 guide, no version or date printed; checked 2026-11-23): 180 minutes, 75 questions (65 scored + 10 unscored), scaled 100–1,000, pass 750, compensatory. Domains: sdlc 22 %, config 17 %, resilience 15 %, monitoring 15 %, incident 14 %, security 17 %. No DOP-C03 announced; no French exam. Our mock scores all 75 (about 2.4 min each).
- **Level**: professional DevOps engineer (2+ years on AWS). Out of scope: advanced networking, deep security advice to developers, database design and tuning, full-stack code.
- **Types**: `single` 4 options, 1 correct (78–88 %); `multi` 5 options / 2 correct ("Choose two.") or 6 / 3 ("Choose three."), 12–22 %, all or nothing.
- **Stems**: 5–10 sentences: a company with several accounts or Regions, its existing pipeline, fleet or monitoring setup, a failure or new requirement, constraints (compliance, approval, no downtime), then the qualifier ("LEAST operational overhead", "MOST cost-effective", "LEAST downtime", "MOST automated", "without changing application code") and "Which solution will meet these requirements?". Options are complete automation designs (trigger + service + target + permissions); each distractor fails one constraint (manual step, wrong account, wrong hook, custom code where a managed feature exists). Hard = the qualifier or one buried detail decides.
- **Traps**: CodePipeline stages/actions, approvals, cross-account deployments (KMS-encrypted artifact bucket + cross-account roles); CodeBuild buildspec, reports, caching; CodeDeploy appspec hooks and deployment configurations for EC2/ECS/Lambda, alarm rollback; blue/green vs canary vs linear vs rolling vs immutable; CloudFormation StackSets, drift, change sets, custom resources, cfn helper scripts, CDK; Systems Manager Automation, Patch Manager, State Manager, Parameter Store vs Secrets Manager rotation; Config rules, conformance packs, auto-remediation; EventBridge patterns and cross-account buses; CloudWatch composite alarms, metric filters, Logs Insights, subscriptions, anomaly detection, Synthetics; X-Ray vs OpenTelemetry; Auto Scaling lifecycle hooks, warm pools; Route 53 failover, Aurora Global Database, DynamoDB global tables, cross-Region AWS Backup; Organizations, SCPs, Control Tower; ECR scanning, Inspector, GuardDuty, Macie, Security Hub CSPM.
