# AZ-700 exam profile

- Associate level (Azure Network Engineer Associate, "intermediate"). 100 minutes, about 40–60 questions, pass at 700/1000, proctored, Microsoft Learn accessible during the exam. Case study and "does the solution meet the goal" series; interactive items possible.
- **Design and implement**: half "which service / SKU / topology meets the requirements", half "what should you configure, and in which order". Deep on behaviour: effective routes and route selection, NSG rule evaluation, DNS resolution paths, peering and gateway transit settings, SNAT, health probes.
- **Stems are medium to long**: an environment given as tables (virtual networks, address spaces, subnets, peerings, route tables, NSG rules, gateways) or an exhibit, then a precise need. Typical forms: "You need to ensure that VM1 can ... What should you do?", "Which three actions should you perform in sequence?", Yes/No statements on a topology, drop-downs completing a configuration or an Azure CLI / PowerShell command.
- **Formats**: single choice (35–45 %), "select two/three" (10–15 %), three Yes/No statements (10–15 %), answer-area drop-downs (10–15 %), drag and drop (5–10 %), ordered steps (5–10 %), occasional hot area.
- **Hands-on level**: portal settings with their exact names, reserved subnet names and minimum sizes (GatewaySubnet, AzureBastionSubnet, AzureFirewallSubnet, RouteServerSubnet), gateway and firewall SKUs, limits that drive a design. Commands are read, rarely written.
- **Distractors**: Load Balancer / Application Gateway / Front Door / Traffic Manager; service endpoint / private endpoint / Private Link service; VPN Gateway / ExpressRoute / Virtual WAN; NSG / ASG / Azure Firewall / WAF / security admin rules; private DNS zones / DNS Private Resolver / custom DNS.
- **Classic traps**: peering is not transitive; UDR vs BGP vs system route precedence; forced tunneling side effects; private endpoint DNS; Basic SKUs retired (Standard public IP and load balancer only).
- **Out of scope**: VM, storage or identity administration beyond what a network needs; on-premises device configuration.
- Difficulty: 30 % easy, 50 % medium, 20 % hard.
