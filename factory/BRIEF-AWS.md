# Certidrill content factory — AWS addendum

Read `factory/BRIEF.md` first: every rule there applies, **except** the points below, which replace the Microsoft-specific ones for AWS certifications (`content/saa-c03/`, later `content/clf-c02/`...).

## What changes for AWS

1. **Sources.** The scope is the official AWS exam guide (`docs.aws.amazon.com/aws-certification/latest/...`) and the facts come from AWS documentation: `docs.aws.amazon.com` (user guides, developer guides, FAQs under `aws.amazon.com/<service>/faqs/`, the Well-Architected Framework `docs.aws.amazon.com/wellarchitected/`). Verify with WebFetch every limit, quota, default, storage class, instance family, price model, retirement and service name you are not certain of. AWS renames and retires services: check that a service is still offered to new customers before using it (for example AWS CodeCommit, Amazon QLDB, AWS Snowmobile, Amazon S3 Select, AWS OpsWorks, AWS Cloud9 closed to new customers). If you cannot verify a fact, leave it out.
2. **Fictional companies**: do not use Microsoft's placeholder names (Contoso, Fabrikam, Litware...). Use neutral invented names ("a media company", "a retail company", "AnyCompany", "Example Corp") as AWS-style scenarios do.
3. **Question types: `single` and `multi` only.** The real exam has only multiple choice (1 correct of 4) and multiple response (2 or more correct of 5 or more, "Choose two." / "Choose three." at the end of the stem). No case study, no Yes/No series, no drop-down, no drag and drop. Single: 4 options. Multi: 5 options with 2 correct, or 6 options with 3 correct.
4. **Stem style (SAA-C03).** A scenario of 2–5 sentences: a company, its current architecture, one or more requirements with a deciding qualifier ("with the LEAST operational overhead", "MOST cost-effective", "with the highest availability", "without changing the application code"), then the question ("Which solution will meet these requirements?"). Options are full solutions in one or two sentences, all plausible AWS designs; the distractors fail one stated requirement. The qualifier decides between two technically valid answers: say which requirement each wrong option fails in `explanation.options`.
5. **References**: 1–2 AWS documentation pages **that you fetched**, English URL (`https://docs.aws.amazon.com/...` or `https://aws.amazon.com/.../faqs/`), title = page title. In course chapters, links (if any) use the **same English URL in both languages** (the EN/FR link check compares them as they are).
6. **French terminology.** AWS service and feature names stay in English (Amazon S3, S3 Standard-IA, Auto Scaling group, security group, NAT gateway, Multi-AZ, Reserved Instances, Savings Plans), as in AWS's own French documentation (`docs.aws.amazon.com/fr_fr/`). Common nouns are translated as in that documentation: compartiment (bucket) at first mention then « compartiment S3 », groupe de sécurité, passerelle NAT, sous-réseau, zone de disponibilité, Région (capital R as AWS writes it), table de routage, rôle IAM, politique (policy — AWS fr_fr uses « politique »), instance, volume, point de terminaison. When AWS fr_fr is inconsistent, give the English term in parentheses at first use. Typography rules of BRIEF.md (spaces before `: ; ? !`, straight apostrophes, « ») apply.
7. **Code in courses**: `bash` (AWS CLI), `json` (IAM policies, bucket policies), `yaml` (CloudFormation, SAM), `text`. No other language.
8. **Exam profile**: `factory/profiles/<cert>.md`; scope = `content/<cert>/objectives.yaml` and the in-scope / out-of-scope service lists of the exam guide (in the profile).
