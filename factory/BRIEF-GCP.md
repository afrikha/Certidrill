# Certidrill content factory — Google Cloud addendum

Read `factory/BRIEF.md` first, then `factory/BRIEF-EN-ONLY.md` (Google Cloud exams are not offered in French: **English only**). Every rule there applies, **except** the points below, which replace the Microsoft-specific ones for Google Cloud certifications (`content/gcp-pca/`, `content/gcp-ace/`…).

1. **Vendor.** `certification.vendor: Google Cloud`.
2. **Sources.** Scope: the official exam guide (in `factory/profiles/<cert>.md`). Facts: Google Cloud documentation (`docs.cloud.google.com/...`; the old `cloud.google.com/<product>/docs/...` URLs redirect there), the Architecture Center (`cloud.google.com/architecture/...`, including the Well-Architected Framework), product pricing and quotas pages, release notes. Verify with WebFetch every limit, quota, default, SLA figure, machine family, storage class, product name, launch stage (Preview vs GA) and retirement you are not certain of. **Google renamed many products in 2025–2026** (for example Vertex AI and Agent Builder offerings now presented under the "Gemini Enterprise Agent Platform" / "Agent Platform" names used by the exam guide, Cloud Functions → Cloud Run functions, BeyondCorp Enterprise → Chrome Enterprise Premium, Container Registry → Artifact Registry, Cloud Debugger and Cloud Profiler changes): use the name the current docs and the exam guide use, and check it. A Preview feature is never the correct answer. If you cannot verify a fact, leave it out.
3. **Question types: `single` and `multi` only.** The real exam has multiple choice (1 correct of 4) and multiple select ("Choose two." / "Choose three." at the end of the stem; 5 options for two answers, 6 for three). No Yes/No series, no drop-down, no drag and drop. Case studies exist (2 per exam, 20–30 % of the questions).
4. **Stem style.** A scenario of 2–5 sentences about a company (invented names: "a media company", "Example Corp", "Cymbal"-style invented brands are fine but never Google's published case study companies Altostrat, Cymbal Retail, EHR Healthcare, KnightMotives), its current architecture and constraints, then the question ("What should you do?", "Which solution should you recommend?"). Options are complete Google Cloud designs or actions, all plausible; the deciding requirement is explicit (cost, latency, operational overhead, compliance, least privilege, minimal changes, Google-recommended practice). `explanation.options` says which requirement each wrong option fails.
5. **Case studies** (Professional Cloud Architect only; Associate Cloud Engineer has none). Original companies only, never Google's published ones. Format of Google's case studies: Company overview, Solution concept, Existing technical environment, Business requirements, Technical requirements, Executive statement (tabs). Questions depend on the case text.
6. **References**: 1–2 Google Cloud documentation pages **that you fetched** (English URL), title = page title.
7. **Course code.** `bash` (gcloud, gsutil/gcloud storage, bq, kubectl), `yaml`, `json`, `text`. Terraform (`hcl`) is not an allowed fence: show Terraform in `text` only if needed.
8. **Exam profile**: `factory/profiles/<cert>.md`.
